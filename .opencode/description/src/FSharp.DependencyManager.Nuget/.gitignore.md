# .gitignore

## Pipeline role
Folder-scoped gitignore for `src\FSharp.DependencyManager.Nuget`.

## Content
```
FSharp.DependencyManager.Nuget.nuget.props
```

## Why
The NuGet dependency manager generates `FSharp.DependencyManager.Nuget.nuget.props` as
build output when resolving packages (the file fed to NuGet's `RestoreAdditionalProjectSources`
/ restore input by the manager). The generated file is a build artifact and must not be
committed, hence it is ignored at the same location where it is produced.
