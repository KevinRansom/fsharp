# printf.fsi

## Overview

This is the signature (interface) file for `printf.fs`, in namespace `Microsoft.FSharp.Core`. It declares only the public surface: the `PrintfFormat`/`Format` types and the `Microsoft.FSharp.Core.Printf` module, with full XML documentation (which becomes the reference docs and IntelliSense text).

## Format types

- `PrintfFormat<'Printer, 'State, 'Residue, 'Result>`
  - `new: value: string -> PrintfFormat<...>` — construct from a raw format string.
  - `new: value: string * captures: objnull array * captureTys: Type array -> PrintfFormat<...>` — construct for interpolated strings (captured expressions and the `%A` expression types).
  - `member Value: string` — the raw format text.
  - `member Captures: objnull array` — captures associated with an interpolated string.
  - `member CaptureTypes: Type array` — capture types associated with an interpolated string.
  - Type parameters documented as: `Printer` (function type generated by printf), `State` (passed to `%a` formatters), `Residue` (value produced by the printf action, e.g. `sprint` produces a string), `Result` (value produced after post processing, e.g. `failwithf` builds a string then raises).

- `PrintfFormat<'Printer, 'State, 'Residue, 'Result, 'Tuple>`
  - Inherits `PrintfFormat<'Printer, 'State, 'Residue, 'Result>`.
  - Adds a `Tuple` type parameter (tuple of values generated by scan/match). Two constructors mirroring the 4-parameter form.

- `Format<'Printer, 'State, 'Residue, 'Result>` = `PrintfFormat<...>` and `Format<'Printer, 'State, 'Residue, 'Result, 'Tuple>` = `PrintfFormat<...>` — abbreviations.

## `module Printf` (`[<CompilationRepresentation(CompilationRepresentationFlags.ModuleSuffix)>]`)

Declares the format type abbreviations used throughout the API:

- `BuilderFormat<'T, 'Result> = Format<'T, StringBuilder, unit, 'Result>` and `BuilderFormat<'T>`.
- `StringFormat<'T, 'Result> = Format<'T, unit, string, 'Result>` and `StringFormat<'T>`.
- `TextWriterFormat<'T, 'Result> = Format<'T, TextWriter, unit, 'Result>` and `TextWriterFormat<'T>`.

Public functions and their compiled names:

- `bprintf: builder: StringBuilder -> format: BuilderFormat<'T> -> 'T` — `PrintFormatToStringBuilder`; print to a `StringBuilder`.
- `fprintf: textWriter: TextWriter -> format: TextWriterFormat<'T> -> 'T` — `PrintFormatToTextWriter`; print to a `TextWriter`.
- `fprintfn: ...` — `PrintFormatLineToTextWriter`; like `fprintf` plus a newline.
- `eprintf / eprintfn` — `PrintFormatToError` / `PrintFormatLineToError`; format to `stderr` (optionally with newline).
- `printf / printfn` — `PrintFormat` / `PrintFormatLine`; format to `stdout`.
- `sprintf: format: StringFormat<'T> -> 'T` — `PrintFormatToStringThen`; print to an internal string buffer and return the string.
- `kbprintf: continuation: (unit -> 'Result) -> builder: StringBuilder -> format: BuilderFormat<'T, 'Result> -> 'T` — `PrintFormatToStringBuilderThen`; `bprintf` with a final result function.
- `kfprintf: continuation: (unit -> 'Result) -> textWriter: TextWriter -> format: TextWriterFormat<'T, 'Result> -> 'T` — `PrintFormatToTextWriterThen`; `fprintf` with a final result function.
- `kprintf: continuation: (string -> 'Result) -> format: StringFormat<'T, 'Result> -> 'T` — `PrintFormatThen`; like `printf` with a continuation (e.g. to force a flush).
- `ksprintf: continuation: (string -> 'Result) -> format: StringFormat<'T, 'Result> -> 'T` — `PrintFormatToStringThen`; `sprintf` with a continuation.
- `failwithf: format: StringFormat<'T, 'Result> -> 'T` — `PrintFormatToStringThenFail`; format to a string then raise an `Exception` with that message.

Each function carries rich XML `<summary>`, `<param>`, `<returns>`, and `<example>` documentation covering both classic `"%d"`-style format placeholders (described as `%[flags][width][.precision][type]`) and F# interpolated strings.
