# .editorconfig

## Pipeline role
Per-folder editorconfig applying **more conservative** formatting rules to FSharp.Core than
the repo default — FSharp.Core intentionally has denser lines/layout.

## Rules (`[*.fs]`)
- `max_line_length=120` — allow lines up to 120 chars (FSharp.Core pre-existing style).
- `fsharp_max_function_binding_width=1` — keep function bindings narrow (influences
  Fantomas/editor formatting of lambdas and `let` bindings).
- `fsharp_max_if_then_else_short_width=40` — `if/then/else` stays on one line only up to
  40 chars width.

## Role
When FSharp.Core sources are formatted/edited (Fantomas-based tooling respects
.editorconfig), these settings keep the library's established dense style instead of
reflowing to the compiler's looser defaults. Comment explains: "FSharp.Core uses more
conservative settings - more lines etc."
