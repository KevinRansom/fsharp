# prim-types-prelude.fsi

## Overview

This is the public API signature for the primitive-type prelude (namespace `Microsoft.FSharp.Core`). Its exact filename is depended upon by graph-based type-checking in the F# compiler, so the name must be preserved. It declares the same type abbreviations and primitive types as the implementation, but with full XML documentation. It begins with `#nowarn "35"` and `#nowarn "61"` to suppress warnings about the primitive operators/null-repr union cases.

## Basic type abbreviations (category "Basic Types")

- `obj = Object`; `objnull = obj | null` (nullable reference types alias)
- `exn = Exception`
- `nativeint = IntPtr`; `unativeint = UIntPtr`
- `string = String`
- `float32 = Single`; `float = Double`; `single = Single` (identical to `float32`); `double = Double` (identical to `float`)
- `sbyte = SByte`; `byte = Byte`; `int8 = SByte`; `uint8 = Byte`
- `int16 = Int16`; `uint16 = UInt16`; `int32 = Int32`; `uint32 = UInt32`; `int64 = Int64`; `uint64 = UInt64`
- `char = Char`; `bool = Boolean`; `decimal = Decimal`
- `int = int32`; `uint = uint32`

## Array types

- `'T [``]`` = (# "!0[]" #)` — single-dimensional, zero-based arrays.
- `'T [,]`, `[,,]`, `[,,,]`, `[,,,,]` ... through `[,,,,...,]` (ranks 2 to 32) — multidimensional zero-based array abbreviations, each with documentation of the rank.
- `'T array = 'T[]` — the public `array` abbreviation (category "Basic Types").

## Pointer types (category "ByRef and Pointer Types")

- `nativeptr<'T when 'T : unmanaged> = (# "native int" #)` — an unmanaged native pointer used for interop; may produce unverifiable code. Values generated by the `NativePtr` module.
- `voidptr = (# "void*" #)` — an untyped unmanaged native pointer.
- `ilsigptr<'T> = (# "!0*" #)` — a Common IL Signature Pointer; documented with usage guidance that it cannot be used in generic type parameters and should be converted to `nativeptr<'T>` for F# use.
