# FSCore.ja.xlf

Pipeline role: XLIFF satellite localization resource for the FSCore string table (src/FSharp.Core/FSCore.resx) of FSharp.Core runtime messages surfaced through the core library SR resource during program execution; compiled into a satellite resource loaded by the resource manager for the Japanese culture.

- File format: XLIFF 1.2 XML (xliff-core-1.2-transitional) with one <file> element, source-language "en", target-language "ja", original "../FSCore.resx".
- Localizes: FSCore table in src/FSharp.Core/FSCore.resx (e.g. matchCasesIncomplete, addressOpNotFirstClass, arraysHadDifferentLengths).
- Locale: ja = Japanese.
- Trans-units: ~142.
- Conventions: mostly short single-line runtime messages, some with indexed placeholders; each unit carries an empty <note />.
