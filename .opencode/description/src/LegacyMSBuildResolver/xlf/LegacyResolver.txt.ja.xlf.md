# LegacyResolver.txt.ja.xlf

Pipeline role: XLIFF satellite localization resource for the LegacyResolver string table (src/LegacyMSBuildResolver/LegacyResolver.txt, base of LegacyResolver.resx) of diagnostics reported by the legacy MSBuild reference resolver (LegacyMSBuildReferenceResolver); compiled into a satellite resource loaded by the resource manager for the Japanese culture.

- File format: XLIFF 1.2 XML (xliff-core-1.2-transitional) with one <file> element, source-language "en", target-language "ja", original "../LegacyResolver.resx".
- Localizes: LegacyResolver table in src/LegacyMSBuildResolver/LegacyResolver.txt (assemblyResolution* resolution-source messages).
- Locale: ja = Japanese.
- Trans-units: 4 (assemblyResolutionFoundByAssemblyFoldersKey, assemblyResolutionFoundByAssemblyFoldersExKey, assemblyResolutionNetFramework, assemblyResolutionGAC).
- Conventions: short single-line messages without placeholders; each unit carries an empty <note />.
