# FSBuild.txt.tr.xlf

Pipeline role: XLIFF satellite localization resource for the FSBuild string table (src/FSharp.Build/FSBuild.txt, base of FSBuild.resx) of F#-specific MSBuild task messages used by the FSharp.Build tasks (Fsc, Fsi, MapSourceRoots, SubstituteText); compiled into a satellite resource loaded by the resource manager for the Turkish culture.

- File format: XLIFF 1.2 XML (xliff-core-1.2-transitional) with one <file> element, source-language "en", target-language "tr", original "../FSBuild.resx".
- Localizes: FSBuild table in src/FSharp.Build/FSBuild.txt (toolpathUnknown, mapSourceRoots* messages).
- Locale: tr = Turkish.
- Trans-units: 5.
- Conventions: single-line messages with indexed placeholders {0}..{3}; each unit carries an empty <note />.
