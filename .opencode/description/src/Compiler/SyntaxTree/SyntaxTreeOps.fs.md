# SyntaxTreeOps.fs

**Purpose**: The internal helper module for the F# syntax tree. It provides the constructors, matchers (active patterns), predicates, and small rewrites the parser actions (`ParseHelpers.fs`), the type-checker, and the F# service use to *build*, *inspect*, and *transform* `SynExpr`/`SynPat`/`SynType` nodes. It also hosts the `SynArgNameGenerator` (state used to name compiler-generated pattern variables), the `SynInfo` sub-module of "val signature" inferences/adjustments, operator-app node builders (`mkSynApp1`…`mkSynBifix`/`Trifix`/`Prefix`), member-flag constructors (`NonVirtualMemberFlags`, `AbstractMemberFlags`, …), and file/directive utilities (`getSourceIdentifierValue`, `parsedHashDirectiveArguments`, …).

**Namespace(s)**: `FSharp.Compiler.SyntaxTreeOps`

**Significant internal logic**:
- **`SimplePatOfPat` / `SimplePatsOfPat`**: convert a full `SynPat` into a `SynSimplePat` plus an optional `SynExpr -> SynExpr` "push" function. When the pattern is not "simple" (contains `OrPatterns`, `Cast`, `IsInst`, `AndPattern`, `Record`, etc.), it produces a `SimplePat` of an `Id` (a fresh `_argN` from `SynArgNameGenerator`) and a `PushPatternToExpr` closure that, when applied to the body expression, injects a `let (argN = <original-pattern>) in …` — this is how the compiler desugars complex lambda parameters.
- **`PushPatternToExpr` / `PushCurriedPatternsToExpr`**: eta-expand a list of patterns into a `SynExpr.LetOrUse` binding wrapping the body; for members it inserts the `this` self-arg first. `normalizeTuplePat` normalizes a curried tuple pattern (e.g. `f (a, b) -> e`) into individual curried args, handling comma ranges and the empty-tuple case.
- **`pushUnaryArg`**: recursively prepends an argument to the function side of an `App` chain (walking `Ident`/`LongIdent`/`DotGet`/`DotIndexedGet`/`TypeApp`) — used for dot-lambda (`a.b <- c`) / indexer / dynamic-arg transformations; fails with `tcDotLambdaAtNotSupportedExpression` on unexpected shapes.
- **Operator builders**: `mkSynInfix` marks the inner `App` with `isInfix` and `ExprAtomicFlag`; `mkSynBifix`/`Trifix`/`PrefixPrim` compose `App` trees via the `mkSynAppN` chain. `mkSynOperator` produces the `SynExpr.Ident(Ident(CompileOpName oper))` node (so `+` becomes `op_Addition` here, via `PrettyNaming.CompileOpName`). `opNameParenGet` / `opNameQMark` memoize the compiled forms of `.()` and `?`.
- **`SynInfo` — val-signature reconstruction**: rebuilds the `SynArgInfo` arity structure from a `SynBinding`/member (curried arg groups, the self-metadata arg, empty-tuple arg for the property getter, the setter arg, optional args, and `AdjustArgsForUnitElimination` for the `(unit)` arg dropped at the IL level). `InferSynValData` produces `emptySynValData` and friends.
- **Member flags**: `NonVirtualMemberFlags`, `CtorMemberFlags`, `ClassCtorMemberFlags`, `OverrideMemberFlags`, `AbstractMemberFlags`, `StaticMemberFlags`, `ImplementStaticMemberFlags` compose `SynMemberFlags` for the given `SynMemberKind` (property/get/set/indexer/method). `getGetterSetterAccess` derives the `get`/`set` access from a `SynValSigAccess` + member kind + language version.
- **`findSynAttribute`**: inline search that matches the last segment of an attribute's lid against the given `attrName`, trying both with and without the trailing `Attribute` — a *cheap untyped* check (the .fsi documents that this should only be used when absolutely necessary, since it does not resolve assemblies or type aliases).
- **`synExprContainsError`**: recursive predicate used to short-circuit checking over parse-error-recovery nodes (`FromParseError`, `ArbitraryAfterError`, `DiscardAfterMissingQualificationAfterDot`).
- **`fl
attenSequentials` / `Sequentials`**: linearize a chain of `SynExpr.Sequential` into a list (for codegen/CE expansion).
- **`desugarGetSetMembers`**: rewrites `GetSetMember`/`AutoProperty` into `Member` get/set defs so downstream passes see only simple members (used on the tree before `SynInfo` inference).
- **`getSourceIdentifierValue` / `applyLineDirectivesToSourceIdentifier`**: compute the value of `__SOURCE_FILE__`/`__SOURCE_DIRECTORY__`/`__LINE__` keyword strings from the path map and line directives.
- **`parsedHashDirectiveArguments`**: converts `ParsedHashDirectiveArgument` list into a list of strings for a given `LanguageVersion` (validates `#lang` / `#nowarn` etc.).
- **`addEmptyMatchClause`**: produces a `SynMatchClause` with a `SynPat.Const Unit` (the "empty catch-all").

**Cross-references**: `SyntaxTreeOps.fsi` (public contract), `SyntaxTree.fs` (the AST types), `SyntaxTrivia.fs` (trivia fields used by some constructors), `ParseHelpers.fs` (the big `mkSynMemberDefnGetSet` etc. consume these builders), `PrettyNaming.fs` (`CompileOpName`, `parenGet`, `qmark` used by the op builders), `Diagnostics` (error reporting in `pushUnaryArg`, `synExprContainsError`), `Features` (language-version gating in `parsedHashDirectiveArguments`).
