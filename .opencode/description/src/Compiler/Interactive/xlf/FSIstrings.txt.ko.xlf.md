# FSIstrings.txt.ko.xlf

Pipeline role: XLIFF satellite localization resource for the FSIstrings fsi string table (src/Compiler/Interactive/FSIstrings.txt, base of FSIstrings.resx) covering fsi.exe usage/help text and interactive-service diagnostics in Compiler/Interactive; compiled into a satellite resource loaded by the resource manager for the Korean culture.

- File format: XLIFF 1.2 XML (xliff-core-1.2-transitional) with one <file> element, source-language "en", target-language "ko", original "../FSIstrings.resx".
- Localizes: FSIstrings table in src/Compiler/Interactive/FSIstrings.txt (usage banners, #help/#load descriptions, fsi diagnostics).
- Locale: ko = Korean.
- Trans-units: 61.
- Conventions: indexed placeholders {0}..{2}; XML-escaped angle brackets (&lt; &gt;) and escaped quotes in F# snippets; a few status "new" units that mirror the English source (e.g. the learn.microsoft.com help link).
