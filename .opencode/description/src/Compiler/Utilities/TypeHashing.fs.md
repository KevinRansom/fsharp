# TypeHashing.fs

**Purpose**: Deterministic, cross-process-stable hashing of F# compiler types and members, used to (a) compute stable fingerprints of member signatures for IVT (internal visibility) / identity checks, and (b) produce a conservative structural fingerprint of `TType` for use as the key of the type-subsumption cache during type inference. It deliberately uses a stable string hash (FNV-1a) rather than `String.GetHashCode` (which is randomized in .NET 6+) so hashes do not depend on process hash randomization, and it incorporates "observer visibility" so internal-only members are hashed to 0 (omitted) when observing from outside the assembly.

**Namespace(s)**: None at file scope — declared as `module internal Internal.Utilities.TypeHashing`.

**Modules / Types declared**:

- `type ObserverVisibility` — UDT: `PublicOnly | PublicAndInternal` (controls which members are visible to a fingerprinting observer, e.g. IVT attribute).
- `[<AutoOpen>] module internal HashingPrimitives` — `type Hash = int`; `hashStableString` (FNV-1a 32-bit over UTF-16 code units, deterministic across processes), `hashText`, `combineHash`/`pipeToHash`/`addFullStructuralHash`, `hashListOrderMatters` (skip 0-valued "hidden" entries; used for ordered lists like type args, fields, properties), `hashListOrderIndependent` (XOR fold, order-insensitive lists like attributes/constraints), operator `(@@)`, and `[<Literal>] MaxTokenCount = 256` (token cap for structure fingerprints — bounds memory and prevents infinite type loops).
- `[<AutoOpen>] module internal HashUtilities` — `hashTyconRefImpl (tcref: TyconRef)`; maps the entity kind of a `TyconRef` to a `TextTag` (`Namespace`, `Module`, `Alias`, `Delegate`, `Enum`, `Struct`, `Interface`, `Union`, `Record`, else `Class`) and combines that with the demangled name and the compilation-path access path (order matters).
- `module HashIL` — hashing of `FSharp.Compiler.AbstractIL.IL` types: `hashILTypeRef` (enclosing path + name), `hashILArrayShape` (rank only), `hashILType` (recursive over `Void/Array/Value/Boxed/Ptr/Byref/FunctionPointer/TypeVar/Modified`), `hashILCallingSignature`.
- `module HashAccessibility` — `isHiddenToObserver (TAccess access) (observer: ObserverVisibility) : bool`: an accessibility path is hidden from a `PublicOnly` observer unless an IVT-like exception admits it; all-internal comp paths are visible to a `PublicAndInternal` observer.
- `module rec HashTypes` — hashing of typed tree (`TType`) and signatures: `hashTyconRef`, `hashMemberFlags`, `hashAttributeList` (order-independent), `hashTyparRef(WithInfo)`, `hashConstraint g (tp, tpc)` (every `TyparConstraint` case gets a distinct tag 1..15), `hashConstraints`, `hashTraitWithInfo` (member logical name, flags, compiled return and object/arg types), `hashMeasure g unt` (units-of-measure: vars and constants with their `Rational` exponents, order-independent), `hashTType g ty` (the main entry: union cases, applied types, anon records (names + structness), tuples (structness), forall, functions via `stripFunTy`, variables with attributes, measures), `hashArgInfo`/`hashCurriedArgInfos`, `hashTopType g argInfos retTy cxs`, `hashTyparDecls`, `hashUncurriedSig`, `hashMemberSigCore`, `hashMemberType g vref typarInst argInfos retTy` (uses `PartitionValRefTypars` to also fold in member-to-parent inst and method typars).
- `module HashTastMemberOrVals` — hashing of members and values: `hashMember (g, observer) typarInst (v: Val)` (member flags, apparent enclosing entity, member type, val flags `PickledBits`, mangled display name, attributes — all 0 if hidden to observer), `hashConst (constVal: Const)` (exhaustive over const kinds; strings hashed stably; `Const.Unit`/`Const.Zero` = 0), `hashNonMemberVal (g, observer) (tps, v, tau, cxs)` (name, typar decls, top type, flags, attributes, and — for deterministic builds — a hash of the literal constant value when present), and the public entry `hashValOrMemberNoInst (g, obs) (vref: ValRef)`.
- `module StructuralUtilities` — structural type fingerprints (see below):
  - `[<Struct; NoComparison; RequireQualifiedAccess>] type TypeToken` — UDT of fingerprint tokens: `Stamp of int`, `UCase of int`, `Nullness of int`, `NullnessUnsolved`, `TupInfo of int`, `Forall of int`, `MeasureOne`, `MeasureDenominator/Numerator of int`, `Solved of int`, `Unsolved of int`, `Rigid of int`.
  - `[<CustomEquality; NoComparison>] type TypeStructure` — `Stable of hash:int * tokens:TypeToken[] | Unstable of hash:int * tokens:TypeToken[] | PossiblyInfinite`; `Stable` and `Unstable` values are distinguished in `GetHashCode` (Unstable ORs `0x40000000`) and in `Equals`; `PossiblyInfinite` is a singleton.
  - `type private GenerationContext()` — thread-local state: `TyparMap` (stamp -> local id), `Tokens` (`ResizeArray<TypeToken>`), `EmitNullness`, `Stable`; `Reset()`.
  - `let private context = ThreadLocal<GenerationContext>` — one context per thread, reset per call.
  - Token emitters: `hashTokenArray`, `encodeNullness`/`emitNullness` (marks the context Unstable — nullness may still be solved), `emitStamp` (64-bit stamps emitted as one or two 32-bit `Stamp` tokens), `emitMeasure` (recursive: vars, constants, products, inverses, `One`, rational powers with `GetNumerator`/`GetDenominator`), `emitTType` (recursive over `TType_ucase/app/anon/tuple/forall/fun/var/measure`; registers typar stamps in a `TyparMap` for local-id emission; solved variables emit the solution; rigid variables emit `Rigid id`, others `Unsolved id`, and mark the context Unstable).
  - `getTypeStructureOfStrippedTypeUncached ty` — runs the emitter; if the token array hit `MaxTokenCount` (256) returns `PossiblyInfinite` (possible infinite type); otherwise `Stable` or `Unstable` depending on whether the context was marked unstable.
  - `getTypeStructureOfStrippedType` — memoized via `WeakMap.cacheConditionally` (only `Stable` results are cached).
  - `tryGetTypeStructureOfStrippedType ty : TypeStructure ValueOption` — the entry point: `ValueNone` for possibly-infinite types, else the `TypeStructure`.

**Significant internal logic**:

- **Two consumers, two granularities**: (1) signature-level fingerprints — `hashValOrMemberNoInst` combines member name/flags/enclosing type/args/return/constraints, with visibility hiding (internal members hash to 0 and are omitted from `hashListOrderMatters` folds) so that public and internal observations of a type differ appropriately; this feeds the compiler's identity/IVT reasoning. (2) Type-structure fingerprints — `tryGetTypeStructureOfStrippedType` builds a token sequence identifying the shape of a `TType` (stamps for entities/typars/anon records/measures, case names, tuple structness, forall arity, nullness, solution state). The doc block states its **only** current use is the key of the `typeSubsumptionCache`: it must never give a false positive (two non-subsuming types yielding the same sequence) — false negatives merely reduce cache hit rate. It is explicitly **not** stable across compilations and not a full alpha-equivalence canonicalization.
- **Stability choice**: FNV-1a is used for strings because `String.GetHashCode` is process-randomized on .NET 6+, so "stable" here means stable within a build/configuration, not necessarily reproducible across compiler versions (the module doc says cross-compilation stability is a non-goal).
- **Safety caps**: `MaxTokenCount = 256` caps token emission; hitting the cap yields `PossiblyInfinite`, which `tryGetTypeStructureOfStrippedType` maps to `ValueNone` — protecting against recursive/infinite types (e.g. `T = int -> T`).
- **Thread safety**: the `GenerationContext` is `ThreadLocal` and `Reset()` on every use, so no cross-thread state, and it allocates a fresh `ResizeArray<TypeToken>(256)` per thread on first use.
- **Rational exponents** in units of measure are hashed via `rational.fs` (`GetNumerator`/`GetDenominator` after the reduced form) — see cross-references.
