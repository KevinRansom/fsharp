# FSStrings.resx

## Pipeline role
`.resx` resource file for compiler messages that are not part of the numbered
`FSComp.txt` table — parser "expected token" descriptions, constraint-solver and
type-mismatch phrasing, and miscellaneous diagnostics too context-specific for the main
table. It is embedded as `FSStrings.resources` by `FSharp.Compiler.Service.fsproj`.

## Format
Standard ResX v2.0 XML: `<resheader>` schema/reader/writer rows plus `<data name=...>`
entries (359 data entries) with `<value>` (plus `xml:space="preserve"` for
newline-sensitive strings).

## Key string groups
- Constraint-solver unification messages: `ConstraintSolverTupleDiffLengths`,
  `ConstraintSolverInfiniteTypes`, `ConstraintSolverMissingConstraint`, the
  `ConstraintSolverTypesNotInEqualityRelation*` / `SubsumptionRelation` family.
- Nullness warnings: `ConstraintSolverNullnessWarning*` (expected-vs-nullable, dot-access
  dereference warnings, "does not support 'null'").
- Type equation errors: `ErrorFromAddingTypeEquation1/2` and their `...Tuple` variants,
  `ErrorsFromAddingSubsumptionConstraint`, `ErrorFromApplyingDefault1/2`.
- Value-restriction advice (`ValueRestriction`, `ValueRestrictionFunction`), upcast/coercion
  messages (`UpcastUnnecessary`, `TypeTestUnnecessary`, `StaticCoercionShouldUseBox`, the
  `RuntimeCoercion*`/`Indeterminate*Coercion` family), match incompleteness
  (`MatchIncomplete1..4`, `EnumMatchIncomplete1`), signature conformance
  (`ValueNotContained`, `RequiredButNotSpecified`).
- **Parser grammar strings**: the large `Parser.TOKEN.*` group (e.g. `Parser.TOKEN.IDENT`
  -> "identifier", `Parser.TOKEN.RARROW` -> "symbol '->'", keyword spellings) and the
  `NONTERM.*` context suffixes (" in pattern", " in type definition" ...) used to build
  compiler "Unexpected/Expected token" grammar for parser error recovery.

## Consumers
`sr.fs`/`sr.{resx}` typed accessors generated by `FSharpEmbedResXSource`
(`Microsoft.FSharp.Targets`) surface these into the compile; used by parser error
reporting and CheckConstraintSolver. Like FSComp.txt, xlf satellites provide localized
`FSStrings.resources.dll`.
