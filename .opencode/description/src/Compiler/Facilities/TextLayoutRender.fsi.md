# TextLayoutRender.fsi

**Purpose**: The contract for `TextLayoutRender.fs` ("DSL to create structured layout objects with optional breaks and render them"). Publicly exposes `NavigableTaggedText`; internally declares the `LayoutRenderer` abstraction, the `LayoutRender` module (renderers + entry points), and the keyword/separator leaf modules.

**Namespace(s)**: `FSharp.Compiler.Text`
