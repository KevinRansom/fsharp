# UtilsStrings.txt.ru.xlf

Pipeline role: XLIFF satellite localization resource for the UtilsStrings compiler string table (src/Compiler/Facilities/UtilsStrings.txt, base of UtilsStrings.resx) supplying the fsc/fsi product-and-banner strings consumed by Compiler/Facilities/CompilerLocation.fs; compiled into a satellite resource loaded by the resource manager for the Russian culture.

- File format: XLIFF 1.2 XML (xliff-core-1.2-transitional) with one <file> element, source-language "en", target-language "ru", original "../UtilsStrings.resx".
- Localizes: UtilsStrings table in src/Compiler/Facilities/UtilsStrings.txt (buildProductName, fSharpBannerVersion).
- Locale: ru = Russian.
- Trans-units: 2 (buildProductName, fSharpBannerVersion).
- Conventions: short single-line strings; printf-style %s in the text base surfaces as indexed {0}/{1} placeholders in the resx/xlf.
