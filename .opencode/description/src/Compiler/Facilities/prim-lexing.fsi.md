# prim-lexing.fsi

**Purpose**: The contract for `prim-lexing.fs`. Declares the source-text abstractions used as compiler input, and the (internal) lexer runtime — `Position`, `LexBuffer<'Char>`, `UnicodeTables` — that fslex-generated lexers reference. The file header notes the buffer type must stay generic to match FsLex/FsYacc-generated code.

**Namespace(s)**: `FSharp.Compiler.Text`, `Internal.Utilities.Text.Lexing`

**Declarations**:
- `ISourceText` (interface): `Item`, `GetLineString`, `GetLineCount`, `GetLastCharacterPosition`, `GetSubTextString`, `SubTextEquals`, `Length`, `ContentEquals`, `CopyTo`, `GetSubTextFromRange` (throws `ArgumentException` if range outside file boundaries)
- `ISourceTextNew : ISourceText`: adds `GetChecksum` — "Just like ISourceText, but with a checksum. Added as a separate type to avoid breaking changes."
- `module SourceText.ofString`; `module SourceTextNew.ofString` / `ofISourceText`
- `[<Struct>] internal Position`: `FileIndex`, `Line`, `AbsoluteOffset`, `StartOfLineAbsoluteOffset`, `Column`; `NextLine`, `EndOfToken`, `ShiftColumnBy`, `ColumnMinusOne`, `Empty`, `FirstLine`
- `[<Sealed>] internal LexBuffer<'Char>`: "Input buffers consumed by lexers generated by fslex.exe"
  - `StartPos`/`EndPos`; `LexemeView` (valid only until advanced); `LexemeLength` (smaller ⇒ rewind — "Use with caution"); `LexemeChar`, `LexemeContains`, `LexemeString`
  - `BufferLocalStore: IDictionary<string,obj>`; `IsPastEndOfStream`
  - `ReportLibraryOnlyFeatures`, `LanguageVersion`, `SupportsFeature`, `CheckLanguageFeatureAndRecover`
  - Factories: `FromChars`, `FromFunction`, `FromSourceText` (`FromArray(NoCopy)` are internal)
- `[<Sealed>] internal UnicodeTables`: "The type of tables for an unicode lexer generated by fslex.exe" — `static Create: uint16[][] * uint16[] -> UnicodeTables`, `member Interpret: initialState * LexBuffer<char> -> int`

**Cross-references**: Implements prim-lexing.fs; consumed by prim-parsing (generated `FSharpParse`) and the three fslex lexers; language-feature members tie in LanguageFeatures.fs/DiagnosticsLogger.fs.
