# TypedTreeOps.ExprOps.fs

**Purpose**: "TypedTreeOps.ExprOps: address-of operations, expression folding, intrinsic call wrappers, and higher-level expression helpers." A large auto-opened library of (a) **address-of / mutability** analysis (`AddressOps`: `DefensiveCopyWarning`, `Mutates` (AddressOfOp|Definitely/Possibly/Never Mutates), `CanTakeAddressOf*`, `MustTakeAddressOf*`, `mkDerefAddrExpr`, `mkExprAddrOfExpr(Aux)`, `mkTupleFieldGet`, `mkAnonRecdFieldGet`, `mkRecdFieldGet`, `mkUnionCaseFieldGetUnproven`, `is*{RecdOrStructTycon(Ref)AssumedImmutable,ReadOnly}`…), (b) **expression folding** (`ExprFolding`: `IterateRecursiveFixups` (recursive `let` fixups), `JoinTyparStaticReq`, the `ExprFolder<'State>` record, `ExprFolder0`, `FoldImplFile`, `FoldExpr`, `#if DEBUG ExprStats`), (c) **literal / constant / call helpers** (`Makers`: `mk{String,Byte,UInt16,Unit,Int32,Int,Zero,One,Two,MinusOne,TypedZero,TypedOne}` … — see .fsi for the full list), and (d) **high-level transforms** (`ExprTransforms`: `MultiLambdaToTupledLambda`, `AdjustArityOfLambdaBody`, `Make{ApplicationAndBetaReduce,FSharpDelegateInvokeAndTryBetaReduce,ArgsForTopArgs}`, `AdjustVal{ForExpectedValReprInfo,ToHaveValReprInfo}`, `stripTupledFunTy`, `(|ExprValWithPossibleTypeInst|_|)`, `mkCoerceIfNeeded`, `mkCompGenLet{In,MutableIn}`, `AdjustPossibleSubsumptionExpr(s)`, `NormalizeAndAdjustPossibleSubsumptionExprs`, `LinearizeTopMatch`, `etaExpandTypeLambda`, `(|NewDelegateExpr|_|)`, `(|DelegateInvokeExpr|_|)`, `(|OpPipeRight{,2,3}|_|)`, `ClearValReprInfo`, `destInt32`, `destThrow`, `isThrow`, `isIDelegateEventType`, `destIDelegateEventType`).

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Modules declared** (internal; auto-opened; see .fsi for the contract):
- `AddressOps` — defensive-copy / address-of / mutability analysis.
- `ExprFolding` — the `ExprFolder<'State>` record and `FoldExpr`/`FoldImplFile` over an expression tree (with `#if DEBUG ExprStats`).
- `Makers` — the big literal/call factory: `mk*` for literals, `mk{Sequential,ThenDoSequential,CompGen*,Sequentials,GetArg0,AnyTupled,RefTupled(NoTypes|Vars),RecordExpr,AnonRecd,RefCell(Get|Set|ContentsRef),Nil,Cons,Array,CompGenLocalAndInvisibleBind,Unbox,Box,IsInst}`, `mspec_Type_GetTypeFromHandle`, `fspec_Missing_Value`, `mkInitializeArrayMethSpec`, `mkInvalidCastExnNewobj`, `mkCallNewFormat`, and the huge `mkCall{String|GetGeneric{Comparer,ER|PER}EqualityComparer,UnboxFast,TypeTest,TypeOf,TypeDefOf,Dispose,Seq,Create{Instance,Event},Generic{Comparison,Equality,Hash}{Outer,WithComparer},*Operator,DefaultOf,To{Byte,SByte,Int{16,32,64},UInt{16,32,64},Single,Double,IntPtr,UIntPtr,Char,Enum}{Checked,Operator},Bitwise{And,Or,Xor},Shift{Left,Right},Unary{Neg,Not}*,To{Byte,SByte,Integer}{Checked,Operator}}` family, plus the array 1D/2D/3D/4D gets/sets, `mkCall{ArrayLength,Hash,Box,IsNull,Raise,NewDecimal}`, `tryMkCallBuiltInWitness`, `tryMkCallCoreFunctionAsBuiltInWitness`, `TryEliminateDesugaredConstants`, `mkCallSeq{Collect,Using,Delay,Append,Generated,Finally,TryWith,OfFunctions,ToArray,ToList,Map,Singleton,Empty}`, `mkCall{DeserializeQuotationFSharp{20,40}Plus,CastQuotation,LiftValue(WithName|WithDefn),CheckThis,FailInit,FailStaticInit,QuoteToLinqLambdaExpression,OptionToNullable,OptionDefaultValue,Lazy{Delayed,Force},GetString{Char,Length},StaticCall_String_Concat{2,3,4,Array},StringConcat,Decr,Incr,Ldlen,Ldelem,ILAsm{Ceq,Clt}}`, `mk{Null,Throw,ReraiseLibCall,Reraise,Labelled,NullTest,NonNullTest,NonNullCond,IfThen,primMkApp,Apps(Aux),ExprAppAux,AppsAux,TyAppExpr,UnionCaseTest}`.
- `ExprTransforms` — see the long list in the `.fsi` for the full list; in short: the arity/type/lifting helpers for "make this expression work with this expected shape" (subsumption adjustment, eta-expansion, lambda-arity, application+beta-reduction, witness generation…).

**Significant internal logic**: `IterateRecursiveFixups` is the function that walks a `let rec` binding and inserts the `Link` fixes-up (see `TypedTree.fs` `Expr.Link` — the "link node" that is a reference to the value being defined). `ExprFolder<'State>` is the "stateful fold over expressions" pattern: a record of optional callbacks (one per node type) plus an outer "expr" fold — used for invariants, statistics, free-var collection, etc. The `mkCall*Operator*` family dispatches to the right F# operator (checked vs unchecked, generic comparison, etc.) — a thin layer between the checker and the typed-tree. `MakeApplicationAndBetaReduce` / `MakeFSharpDelegateInvokeAndTryBetaReduce` are the "apply this function to these args (and try to beta-reduce if we have a lambda)" helpers used by the F# `App` expression.
