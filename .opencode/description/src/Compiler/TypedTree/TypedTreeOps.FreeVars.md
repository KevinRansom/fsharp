# TypedTreeOps.FreeVars.fs

**Purpose**: The free-variable analysis of the typed tree. A `FreeVars` is a record holding the sets of free `Val`s, `Typar`s, `Tycon`s, `RecdFieldRef`s, and `UnionCaseRef`s in a piece of tree. The `FreeTypeVars` module provides the core "accumulate free variables" functions (over types, traits, tupinfos, vals, typars) and the `Collect*` families (with/without caching, with/without a stack guard), plus the `freeInType/Types/Val` and `freeIn{ModuleTy,...}` entry points. The `MemberRepresentation` module builds the "display representation" of a value — the F# view of its type & args (`GetMemberTypeInFSharpForm`, `GetTypeOfMemberIn{FSharp,Member}Form`, `PartitionVal{,Ref}Typars`, `ReturnTypeOfPropertyVal`, `ArgInfosOf{PropertyVal,Member}`), and the type simplification/pretty-typar machinery (`Prettify*`, `NewPrettyTypars`, `PrettyTyparNames`, `AssignPrettyTyparNames`, `CollectInfo`).

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Modules declared** (internal; see `.fsi` for the contract):
- `FreeTypeVars` — `emptyFree{Locals,RecdFields,UnionCases,Tycons,Typars,Tyvars}`, `unionFree{Locals,RecdFields,UnionCases,Tycons,Typars,Tyvars}`, `typarOrder` (an `IComparer<Typar>`), `isEmptyFreeTyvars`, `FreeVarOptions` (the collect-mode record: `CollectLocals|CollectTypars|CollectLocalsAndTypars|CollectAll|...`, plus `*WithStackGuard` variants), the `accFreeIn{Types,Type,Tycon,Typars,Trait,TraitSln,TupInfo,Val}` family (the core "accumulate" functions), `freeIn{Type,Types,Val}`, `freeIn{Type,Types}LeftToRight(SkippingConstraints)`, `freeInModuleTy`, the `Collect*` entry points (each is a `FreeVarOptions -> <something> -> FreeTyvars( or FreeVars )`), `accFreeIn{Targets,Exprs,SwitchCases,DecisionTree}`, `freeInModuleOrNamespace`, `accFreeInExpr`, `freeInExpr`, `freeInBindingRhs`.
- `MemberRepresentation` — the "display representation" of a value: `GetMemberTypeInFSharpForm`, `checkMemberValRef`, `general{Type,TypeRef}Inst`, `generalizeTyconRef`, `generalizedTyconRef`, `GetValReprTypeInCompiledForm`, `GetFSharpViewOfReturnType`, `GetTypeOfMemberIn{FSharp,Member}Form`, `GetMemberTypeInMemberForm`, `PartitionVal{TyparsTypars,RefTypars}`, `CountEnclosingTyparsOfActualParentOfVal`, `ReturnTypeOfPropertyVal`, `ArgInfosOf{PropertyVal,Member}`, `isTyparOrderMismatch`, `NeedsPrettyTyparName`, `NewPrettyTypars`, `PrettyTyparNames`, `AssignPrettyTyparNames`, `Prettify*` (the big pretty-typar family: `PrettifyType`, `PrettifyInstAndTyparsAndType`, `PrettifyTypePair`, `PrettifyTypes`, `PrettifyDiscriminantAndTypePairs`, `PrettifyInst`, `PrettifyInstAndType`, `PrettifyInstAndTypes`, `PrettifyInstAndSig`, `PrettifyCurriedTypes`, `PrettifyCurriedSigTypes`, `PrettifyInstAndUncurriedSig`, `PrettifyInstAndCurriedSig`), the display helpers (see `.fsi` for the contract), `typeSimplificationInfo0`, `CollectInfo`, `superOfTycon`, `GetTraitConstraintInfosOfTypars`, `GetTraitWitnessInfosOfTypars`.

**Significant internal logic**: The core loop is `accFreeIn*` — each walks a piece of tree and "accumulates" the free variables into a `FreeTyvars` record. `FreeVarOptions` controls *what* to collect (locals only, typars only, all, …) and whether to use a `StackGuard` (to detect/avoid stack overflow on deeply recursive types — used by `Checker.fs` and the FSI). `*WithStackGuard` variants are the safe versions used in the FSI and the "long-running" checks. `CollectInfo` builds the `TypeSimplificationInfo` (the "which of these typars are static / which are measure / which are the 'parent' typars of a val" classification used by `Prettify*`). `PrettyTyparNames`/`NewPrettyTypars`/`AssignPrettyTyparNames` are the "make pretty typar names for display" family (used by the FSI and the documentation generators).

**Cross-references**: `TypedTreeBasics.fs` (identity primitives), `TypedTree.fs` (the `Val`/`Typar`/`Tycon`/`TType` types), `Checker.fs` (uses `Collect*` to compute the "free variables" of a value for scope decisions), `PrettyNaming`/the FSI (uses `Prettify*` and `PrettyTyparNames` for display), `IlxGen.fs` (uses `GetValReprTypeInCompiledForm` / `GetTypeOfMemberInMemberForm` to build the member signatures).
