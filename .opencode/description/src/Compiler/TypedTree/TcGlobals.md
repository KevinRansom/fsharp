# TcGlobals.fs

**Purpose**: The global environment used throughout type checking. The `TcGlobals` instance hard-wires into the compiler the well-known FSharp.Core types, values and attributes (`int`, `string`, `FSharpFunc`, `option`, `seq`, operators, `Ref`, measure types, `PrintfFormat`, Linq QueryBuilder, etc.), and the equivalent `System.*` types and attributes. This lets the compiler recognize these entities by identity and do optimizations (e.g. emitting optimized comparison/hashing calls, intrinsic operator references, `ReflectedDefinition`-related helpers) instead of name-based comparison.

**Namespace(s)**: `FSharp.Compiler` (module `internal FSharp.Compiler.TcGlobals`).

**Declared types**:
- `IntrinsicValRef` — `IntrinsicValRef of NonLocalEntityRef * string * bool * TType * ValLinkageFullKey`; wraps a compiler-known intrinsic value (e.g. an operator) with its type and a `ValLinkageFullKey`; members `Name`, `DebugText`, `ToString`. `ValRefForIntrinsic: IntrinsicValRef -> ValRef` converts it.
- `CompilationMode` (`[<RequireQualifiedAccess>]`) — `Unset | OneOff | Service | Interactive`; signals how the checker was invoked (FSC process vs. service vs. FSI); gates pipeline features (e.g. type subsumption cache only in one-off compilation).
- `BuiltinAttribInfo` — `AttribInfo of ILTypeRef * TyconRef`; pair of a .NET IL attribute type ref and the matching `TyconRef` (members `TypeRef`, `TyconRef`).
- `TcGlobals` — the big class (ctor takes `compilingFSharpCore`, `ilg: ILGlobals`, `fslibCcu: CcuThunk`, `directoryToResolveRelativePaths`, `isInteractive`, `checkNullness`, `useReflectionFreeCodeGen`, `tryFindSysTypeCcuHelper`, `emitDebugInfoInQuotations`, `noDebugAttributes`, `pathMap`, `langVersion`, `realsig`, `compilationMode`).
- `<module FSharpLib>` (`[<AutoOpen>]`) — FSharp.Core namespace/name constants: `Root="Microsoft.FSharp"`, `Core`, `CoreOperatorsCheckedName`, `ControlName`, `LinqName`, `CollectionsName`, `LanguagePrimitivesName`, `CompilerServicesName`, `LinqRuntimeHelpersName`, `ExtraTopLevelOperatorsName`, `NativeInteropName`, `QuotationsName` plus the `*Path`/`*PathArray` splits.
- `[<Literal>] tname_*` constants for ~40 well-known BCL type names (`Int32`, `Delegate`, `Enum`, `FlagsAttribute`, `Debugger*` attributes, `RuntimeFieldHandle`, `IsByRefLikeAttribute`, `CompilerGeneratedAttribute`, ...).

**Significant internal logic**: References are built either from FSharp.Core (via `fslibCcu` with namespacing into `CorePath`, `LinqPath`, `CollectionsPath`, `ControlPath`, `CompilerServicesPath`, `QuotationsPath`) or from the BCL (via `tryFindSysTypeCcuHelper` over reference assemblies). When a BCL type can't be found, a *dangling CCU* carrying a diagnostic `tcGlobalsSystemTypeNotFound` is created (so dereferencing later produces a useful error). `isInEmbeddableKnownSet` gates IL embedding of `IsReadOnly`, `IsUnmanaged`, `Nullable`, `NullableContext`, `MemberNotNullWhen`, `DynamicDependency`, `DynamicallyAccessedMemberTypes` attributes (for netstandard2.0 consumers). `knownIntrinsics` is populated lazily by `checker` for fast recognition. In DEBUG builds, `val mutable internal global_g: TcGlobals option` mirrors the live instance for debugging.
