# TypedTreeOps.Remapping.fs

**Purpose**: Implements cross-file (implementation↔signature) remapping of `Entity`/`Val` objects. A `SignatureRepackageInfo` (built by `ComputeRemappingFromImplementationToSignature` / `ComputeRemappingFromInferredSignatureToExplicitSignature`) is a per-`Entity`/`Val` identity map that tells the compiler "in the signature file view, this implementation entity is *that* signature entity", used to (a) publish `internal` things into the signature data, (b) "hiding" non-public members at the assembly boundary (`IsHidden{Tycon,TyconRepr,Val,RecdField}`), (c) build the `ModuleOrNamespace` wrapper for a signature view (`wrapModuleOrNamespace{Type,Contents}InNamespace`, `wrapModuleOrNamespaceType`), and (d) drive the "exporting" pass for `CcuData`/`CcuThunk` (`MakeExportRemapping`). The `ExprAnalysis` module provides `remapExpr` (the big "re-write the typed tree under a Remap" — see `TypedTree.fsi` `remapExpr`), `stripTopLambda`, `InferValReprInfoOf{Expr,Binding}`, `DecideStaticOptimizations`, `remarkExpr`, the loop/try/for active patterns (`(|WhileExpr|_|)`, `(|IntegerForLoopExpr|_|)`, `(|TryWithExpr|_|)`, `(|TryFinallyExpr|_|)`), and misc `isRecdOrStructTyconRefDefinitelyMutable`/`isUnionCase{Ref,Field}Mutable`/`isExn(DefinitelyMutable|FieldMutable)`.

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Modules declared** (internal; see `.fsi` for the contract):
- `SignatureOps` — the "remap implementation↔signature" layer: `ComputeRemappingFromImplementationToSignature`, `ComputeRemappingFromInferredSignatureToExplicitSignature`, `ComputeSignatureHidingInfoAtAssemblyBoundary`, `ComputeImplementationHidingInfoAtAssemblyBoundary`, `mkRepackageRemapping`, `addValRemap`, `valLinkageAEquiv`, `abstractSlotValsOfTycons`, `DoRemap{Tycon,Val}`, `IsHidden{Tycon,TyconRepr,Val,RecdField}`, `foldModuleOrNamespaceTy`, `allValsOfModuleOrNamespaceTy`, `allEntitiesOfModuleOrNamespaceTy`, `freeTyvarsAllPublic`, `freeVarsAllPublic`, `CombineCcuContentFragments`, `MakeExportRemapping`, `updateSeqTypeIsPrefix`, `wrapModuleOrNamespace{Type,Contents}InNamespace`, `wrapModuleOrNamespaceType`, `wrapModuleOrNamespaceContentsInNamespace`, active pattern `(|EmptyModuleOrNamespaces|_|)`.
- `ExprFreeVars` — `emptyFreeVars`, `unionFreeVars`, `accFreeIn{Targets,Exprs,SwitchCases,DecisionTree}`, `freeInModuleOrNamespace`, `accFreeInExpr`, `freeInExpr`, `freeInBindingRhs`.
- `ExprRemapping` — `remapExpr`, `remapAttrib(s)`, `remapPossibleForallTy`, `copyModuleOrNamespaceType`, `copyExpr`, `copyImplFile`, `instExpr`, `allValsOf{ModDef,TopLevelValsOfModDef}`, `mkRemapContext`, `tmenvCopyRemapAndBindTypars`, `mapImmediateValsAndTycons`, `remapTycon{Repr,Aug,ExnInfo}`, `tryStripLambdaN`, `stripTopLambda`, `InferValReprInfoOf{Expr,Binding}`, `DecideStaticOptimizations`, `remarkExpr`, `tyOfExpr`, `accTargetsOfDecisionTree`, `mkAndSimplifyMatch`, and the loop/try/for active patterns `(|WhileExpr|_|)`, `(|IntegerForLoopExpr|_|)`, `(|TryWithExpr|_|)`, `(|TryFinallyExpr|_|)`.
- `ExprAnalysis` — `isRecdOrStructTyconRefDefinitelyMutable`, `isUnionCaseRefDefinitelyMutable`, `isExn{DefinitelyMutable,FieldMutable}`, `isUnionCaseFieldMutable`, `GenWitness{ArgTys,Tys,Ty}` (witness-arg generation for trait-passing code), `accTargetsOfDecisionTree`, `mkAndSimplifyMatch`.

**Significant internal logic**: The key invariant is that a "Remap" is a `TyconRefMap<TyconRef>` + `TyparInstantiation` (see `TypeRemapping`), plus (in `SignatureOps`) a `ValMap<Val,Val>`/`EntityMap<Entity,Entity>` re-mapping. `IsHidden*` answers "should this entity be hidden in the signature view" (e.g. a `private` member, or an implementation-only helper) and `DoRemap*` applies the full re-mapping to a single `Tycon`/`Val`. `freeVarsAllPublic` is used to decide whether a `Val`/`Tycon` can be exported to the assembly boundary. `GenWitness*` builds the `Val`/`TType`/`TType list` for passing trait witnesses as explicit parameters in the "with-witness" form of F# code (the `f$W`-style code mentioned in `TypedTree.fs` around `Expr.WitnessArg`). `remapExpr` is the single most-used function in the file: it re-writes a typed tree under a `Remap` (typar/tycon renaming + substitution) — the workhorse for inlining, type-providing substitution, and signature re-packaging.

**Cross-references**: `TypedTreeOps.Remap.fsi` (the `Remap` type and core operations), `TypedTreeBasics.fs` (identity primitives), `Checker.fs`/`Tast` (uses `remapExpr` during inlining), `SignatureOps` (used by `FsCompiler` to build the `.fsi` signature data), `TypeProviders.fs` (uses `remapExpr` to "de-delegate" provided types), `IlxGen.fs` (witness generation).
