# TypedTreeOps.Attributes.fs

**Purpose**: The attribute-recognition and classification machinery for the typed tree. Given the well-known-attribute flag enums from `WellKnownAttribs` (entity/val/assembly) and the .NET-attribute world (`ILAttribute`s), this module classifies each `Attrib`/`ILAttribute` into its `WellKnown*Attributes` bit flag, computes and caches the aggregate flags on entities/vals ("avoid O(N) linear scans of attribute lists"), classifies IL attributes into the `WellKnownILAttributes` flag set, and exposes a big family of active patterns used to extract attribute payloads ("attributed expression" style). Includes byref/Span type helpers and a debug-print/layout module.

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Significant internal logic**: This file is the single source of truth for "which well-known attribute is present" across the compiler. Classification is done by name matching against `TcGlobals`' built-in refs (see the `attrib_*` members) and cached as `WellKnown*Attributes` bit-flag values so repeated queries are O(1) — the `NotComputed = 1uL <<< 63` sentinel in the `[<Flags>]` enums marks "needs (re)computation". The `filterOutWellKnownAttribs + valMask` path is used when copying an entity into a new context (e.g. a signature file view) so well-known attributes aren't duplicated.
