# TcGlobals.fsi

**Purpose**: Contract for the type checker's global environment. `TcGlobals` is the single place where the compiler pins the "well-known" FSharp.Core types/operators (as `TypedTree.ValRef`/`EntityRef`/`IntrinsicValRef`) and BCL types/attributes; all checking and codegen reference entities through this object so identity-based recognition and optimizations (optimized comparison/hashing calls, intrinsic operator substitution, witness generation) can be done without name string comparison.

**Significant logic (contract)**: All the `*_ty` (canonical F# type references: `int_ty = Microsoft.FSharp.Core.int`, `obj_ty_ambivalent/noNulls/withNulls` reflect nullness), the `*_info` (`IntrinsicValRef`) vs. `*_vref` (`ValRef`) pairs (info carries type + linkage key for unification; vref is the plain reference), the `attrib_*` well-known attribute pairings, and `compilerGenerated` / `DebuggerNonUserCode` attribute templates. Under `#if DEBUG`, `val mutable internal global_g: TcGlobals option` exposes the live instance for debugging.
