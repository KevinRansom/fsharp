# TypedTreeOps.FreeVars.fsi

**Purpose**: Contract for the free-variable analysis of the typed tree. Declares the `FreeTypeVars` module (`empty/union Free{Locals,RecdFields,UnionCases,Tycons,Typars,Tyvars}`, `typarOrder`, `FreeVarOptions` (the `Collect*` modes), the `accFreeIn{Types,Type,Tycon,Typars,Trait,TraitSln,TupInfo,Val}` family, `freeIn{Type,Types,Val}`, `freeIn{Type,Types}LeftToRight(SkippingConstraints)`, `freeInModuleTy`, the `Collect*` entry points, `accFreeIn{Targets,Exprs,SwitchCases,DecisionTree}`, `freeInModuleOrNamespace`, `accFreeInExpr`, `freeInExpr`, `freeInBindingRhs`) and the `MemberRepresentation` module (the display representation of a value — `GetMemberTypeInFSharpForm`, `GetTypeOfMemberIn{FSharp,Member}Form`, `GetValReprTypeInCompiledForm`, `PartitionVal{Typars,RefTypars}`, `ReturnTypeOfPropertyVal`, `ArgInfosOf{PropertyVal,Member}`, `isTyparOrderMismatch`, `NeedsPrettyTyparName`, `NewPrettyTypars`, `PrettyTyparNames`, `AssignPrettyTyparNames`, `Prettify*` family, `typeSimplificationInfo0`, `CollectInfo`, `superOfTycon`, `GetTraitConstraintInfosOfTypars`, `GetTraitWitnessInfosOfTypars`).

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Modules (signatures)**:
- `module FreeTypeVars` — `empty/union Free{Locals,RecdFields,UnionCases,Tycons,Typars,Tyvars}`, `typarOrder: IComparer<Typar>`, `isEmptyFreeTyvars`, the `Collect*` (each a `FreeVarOptions` — see `FreeVarOptions` record for the `CollectLocals|CollectTypars|CollectLocalsAndTypars|CollectAll|...` modes, plus `*WithStackGuard` variants), `accFreeIn{Types,Type,Tycon,Typars,Trait,TraitSln,TupInfo,Val}`, `freeIn{Type,Types,Val}`, `freeIn{Type,Types}LeftToRight(SkippingConstraints)`, `freeInModuleTy`, `Collect*` entry points, `accFreeIn{Targets,Exprs,SwitchCases,DecisionTree}`, `freeInModuleOrNamespace`, `accFreeInExpr`, `freeInExpr`, `freeInBindingRhs`.
- `module MemberRepresentation` — `generatedValueLayout`, `tagEntityRefName`, `richTextOf{EntityRefName,EntityName,EntityRef,Entity}`, `tagValName`, `richTextOfValName`, `fullDisplayTextOf{ModRef,ParentOfModRef,ValRef(AsLayout),TyconRef(AsLayout),ExnRef(AsLayout),UnionCaseRef,RecdFieldRef}`, `fullMangledPathToTyconRef`, `qualifiedMangledNameOfTyconRef`, `qualifiedInterfaceImplementationName`, `trimPathByDisplayEnv`, `prefixOf{StaticReq,InferenceTypar}`, and the pretty-typar families (see the .fs description for the full list).

**Key invariants**: `Collect{Locals,Typars,Tycons,RecdFields,UnionCases,All}` are the "what to collect" modes; `*WithStackGuard` variants are the stack-safe versions (used by the FSI and the long-running checks). `Prettify{Type,Inst,...}` is the "make the typar names pretty (for display)" family — it rewrites a `TType`/`TyparInstantiation`/`TTypes`/`Sig` to have "nice" typar names (e.g. `T`, `U`, `V` in order of first occurrence) and returns the (new) typar constraints.

**Cross-references**: `TypedTreeBasics.fsi`, `TypedTree.fs`/`.fsi`, `Checker.fs`, `Unify.fs`, `PrettyNaming`/the FSI (display), `IlxGen.fs` (member signatures).
