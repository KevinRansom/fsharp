# TypedTreeOps.Transforms.fsi

**Purpose**: Contract for the typed-tree transformation/analysis library: `[<AutoOpen>]` modules providing XmlDoc signature rendering (`XmlDocSignatures`), nullness analysis (`NullnessAnalysis`), type tests and deconstruction patterns (`TypeTestsAndPatterns`), the core expression rewriting (`Rewriting`, with the `ExprRewritingEnv` + `RewriteDecisionTree/Expr/ImplFile`), tuple compilation (`TupleCompilation`, `mkFastForLoop`, `mkCompiledTuple`, `mkGetTupleItemN`, `mkOptimizedRangeLoop`, `DetectAndOptimizeForEachExpression`, `BindUnitVars`), constant evaluation (`ConstantEvaluation`: `IsSimpleSyntacticConstantExpr`, `EvalLiteralExprOrAttribArg`, `EvaledAttribExprEquality`, `ConstToILFieldInit`, and the `ResumableCodePatterns` / `SeqExprPatterns` families of active patterns (`SeqYield|SeqAppend|SeqWhile|SeqTryFinally|SeqUsing|SeqForEach|SeqDelay|SeqEmpty|Seq|_|)`, `ResumableEntryMatchExpr|StructStateMachineExpr|SequentialResumableCode|DebugPointExpr|ResumeAtExpr|ResumableCodeInvoke|_|`)).

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Modules (signatures)**:
- `[<AutoOpen>] module XmlDocSignatures` — `commaEnc/angleEnc`, `ticksAndArgCountTextOfTyconRef`, `typarEnc`, `buildAccessPath`, `XmlDocArgsEnc`, `XmlDocSigOf{Val,UnionCase,Field,Property,Tycon,SubModul,Entity}`, extension members on `ActivePatternElemRef` (`LogicalName`, `DisplayNameCore`, `DisplayName`), `TryGetActivePatternInfo`, `mkChoiceCaseRef`, extension members on `PrettyNaming.ActivePatternInfo` (`DisplayNameCoreByIdx`, `DisplayNameByIdx`, `ResultType`).
- `module NullnessAnalysis` — `nullnessOfTy`, `changeWithNullReqTyToVariable`, `reqTyForArgumentNullnessInference`, `IsNonNullableStructTyparTy`, `HasConstraint` (`[<InlineIfLambda>]`), `IsTyparTyWithConstraint`, `IsReferenceTyparTy`, `Type{NullIsTrueValue,NullIsExtraValue( New),HasAllowNull,NullNever,HasDefaultValue( New)}`, `GetDisallowedNullness`, `GetTyparTyIfSupportsNull`, `(|TyparTy|NullableTypar|StructTy|NullTrueValue|NullableRefType|WithoutNullRefType|UnresolvedRefType|)`, `isComInteropTy`, `mkIsInstConditional`, `canUseUnboxFast`, `canUseTypeTestFast`, `(|Special{Comparable,Equatable,NotEquatable}HeadType|_|)`, `GetMemberCallInfo`.
- `module TypeTestsAndPatterns` — type-predicates and deconstruction (see `.fs`).
- `module Rewriting` — `type ExprRewritingEnv`, `RewriteDecisionTree/Expr/ImplFile`, `IsGenericValWithGenericConstraints`, extension members on `Entity` and `EntityRef`, `ApplyExportRemappingToEntity`.
- `module TupleCompilation` — `mkFastForLoop`, `mkCompiledTuple`, `mkGetTupleItemN`, `(|Zero|_|)`, `type Count = Expr` / `Idx = Expr` / `Elem = Expr` / `Body = Expr` / `Loop = Expr`, `mkOptimizedRangeLoop`, `type OptimizeForExpressionOptions`, `DetectAndOptimizeForEachExpression`, `BindUnitVars`, `mkUnitDelayLambda`.
- `module ConstantEvaluation` — `(|ValApp|_|)`, `GetTypeOfIntrinsicMemberInCompiledForm`, `(|IfThenElseExpr|_|)`, `(|IfUseResumableStateMachinesExpr|_|)`, `IsSimpleSyntacticConstantExpr`, `(|ConstToILFieldInit|_|)`, `EvalLiteralExprOrAttribArg`, `EvaledAttribExprEquality`, `(|Int32Expr|_|)`, `(|IntegralRange|_|)`.
- `module ResumableCodePatterns` — `(|ResumableEntryMatchExpr|_|)`, `(|StructStateMachineExpr|_|)`, `(|SequentialResumableCode|_|)`, `(|DebugPointExpr|_|)`, `(|ResumeAtExpr|_|)`, `(|ResumableCodeInvoke|_|)`.
- `module SeqExprPatterns` — `(|SeqYield|_|)`, `(|SeqAppend|_|)`, `(|SeqWhile|_|)`, `(|SeqTryFinally|_|)`, `(|SeqUsing|_|)`, `(|SeqForEach|_|)`, `(|SeqDelay|_|)`, `(|SeqEmpty|_|)`, `(|Seq|_|)`.

**Key invariants**: `RewriteExpr env` is the main typed-tree transformer used by the checker after `Checker.main`; `DetectAndOptimizeForEachExpression` rewrites a `for i in 0 .. n do ...` loop into an optimized IL for-loop; `EvalLiteralExprOrAttribArg`/`EvaledAttribExprEquality` evaluate constant expressions and attribute arguments for use in `IsMatchingFSharpAttribute`-style checks.

**Cross-references**: `TypedTreeOps.Makers` (construction), `TypedTreeOps.Remap.fsi`, `TypedTreeBasics.fsi`, `TcGlobals.fs`, `PrettyNaming` (XmlDoc), `Checker.fs` (consumer), `IlxGen.fs` (consumer), the F# documentation generator (XmlDoc consumer).
