# TypedTreeOps.Remapping.fsi

**Purpose**: Contract for the cross-file remapping layer. Declares the `SignatureOps` module (building the "remap implementation↔signature" mapping for `Entity`/`Val` identity, "hiding" non-public members at assembly boundaries, and re-packaging a signature `ModuleOrNamespaceType` view), the `ExprFreeVars` module (the `freeInExpr`/`unionFreeVars` machinery used by `ExprAnalysis` and `Checker.fs`), and the `ExprRemapping` module (`remapExpr` — the single most-used typed-tree transformer, plus `copy{Expr,ModuleOrNamespaceType,ImplFile}`, `instExpr`, `InferValReprInfoOf{Expr,Binding}`, `DecideStaticOptimizations`, `remarkExpr`, and the loop/try/for active patterns).

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Modules (signatures)**:
- `module SignatureOps` — `wrapModuleOrNamespace{Type,Contents}InNamespace`, `wrapModuleOrNamespaceType`, `ComputeRemappingFromImplementationToSignature`, `ComputeRemappingFromInferredSignatureToExplicitSignature`, `ComputeSignatureHidingInfoAtAssemblyBoundary`, `ComputeImplementationHidingInfoAtAssemblyBoundary`, `mkRepackageRemapping`, `addValRemap`, `valLinkageAEquiv`, `abstractSlotValsOfTycons`, `DoRemap{Tycon,Val}`, `IsHidden{Tycon,TyconRepr,Val,RecdField}`, `foldModuleOrNamespaceTy`, `allValsOfModuleOrNamespaceTy`, `allEntitiesOfModuleOrNamespaceTy`, `freeTyvarsAllPublic`, `freeVarsAllPublic`, `CombineCcuContentFragments`, `MakeExportRemapping`, `updateSeqTypeIsPrefix`, `(|EmptyModuleOrNamespaces|_|)`.
- `module ExprFreeVars` — `emptyFreeVars`, `unionFreeVars`, `accFreeIn{Targets,Exprs,SwitchCases,DecisionTree}`, `freeInModuleOrNamespace`, `accFreeInExpr`, `freeInExpr`, `freeInBindingRhs`.
- `module ExprRemapping` — `stripTopLambda`, `InferValReprInfoOf{Expr,Binding}`, `DecideStaticOptimizations`, `remapExpr` (the big one), `remapAttrib(s)`, `remapPossibleForallTy`, `copyModuleOrNamespaceType`, `copyExpr`, `copyImplFile`, `instExpr`, `allValsOf{ModDef,TopLevelValsOfModDef}`, `mkRemapContext`, `tmenvCopyRemapAndBindTypars`, `mapImmediateValsAndTycons`, `remapTycon{Repr,Aug,ExnInfo}`, `tryStripLambdaN`, `remarkExpr`, `tyOfExpr`, `accTargetsOfDecisionTree`, `mkAndSimplifyMatch`, active patterns `(|LinearMatchExpr|_|)` / `rebuildLinearMatchExpr`, `(|LinearOpExpr|_|)` / `rebuildLinearOpExpr`, `(|WhileExpr|_|)`, `(|IntegerForLoopExpr|_|)`, `(|TryWithExpr|_|)`, `(|TryFinallyExpr|_|)`.
- `module ExprAnalysis` — `isRecdOrStructTyconRefDefinitelyMutable`, `isUnionCaseRefDefinitelyMutable`, `isExn{DefinitelyMutable,FieldMutable}`, `isUnionCaseFieldMutable`, `GenWitness{ArgTys,Tys,Ty}` (witness-arg generation for trait-passing code).

**Key invariants**: `remapExpr ≡ remapExpr(g, ValCopyFlag, remap, expr)`: re-writes a typed tree under a `Remap` (typar/tycon renaming + substitution) *and* re-scope typars (via `copyAndRemapAndBindTypars`), *and* preserves `Val` identity unless `ValCopyFlag` is set to "copy" — the comment at line 208 of the .fsi notes the distinction: "Tycon and 'module/member' Val objects keep their identity, but the Val objects for all Expr bindings ... reuses Val objects as multiple value bindings, and its been the cause of several subtle bugs."

**Cross-references**: `TypedTreeOps.Remap.fsi` (the `Remap` type and core operations), `TypedTreeBasics.fsi`, `Checker.fs`/`Tast` (uses `remapExpr` during inlining), `SignatureOps` (FsCompiler's `.fsi` generation), `TypeProviders.fs` (de-delegation), `IlxGen.fs` (witness generation).
