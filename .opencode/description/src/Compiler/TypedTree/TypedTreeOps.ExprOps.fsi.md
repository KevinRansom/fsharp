# TypedTreeOps.ExprOps.fsi

**Purpose**: Contract for "TypedTreeOps.ExprOps: address-of operations, expression folding, intrinsic call wrappers, and higher-level expression helpers." Declares four auto-opened modules: `AddressOps` (defensive-copy warning exception, `Mutates` enum, `CanTakeAddressOf*` / `MustTakeAddressOf*` predicates, address/deref/field-get expression builders), `ExprFolding` (`IterateRecursiveFixups`, `JoinTyparStaticReq`, the `ExprFolder<'State>` record and `ExprFolder0`/`FoldImplFile`/`FoldExpr`, plus `#if DEBUG ExprStats`), `Makers` (the large `mk*` family for literals, control flow, seq, arrays, strings, delegates, and every `mkCall*` F# Core call), and `ExprTransforms` (arity/subsumption/type-lambda adjustments, application+beta-reduction, witness/pipe patterns).

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Modules (signatures)**:
- `[<AutoOpen>] module AddressOps` — `exception DefensiveCopyWarning of string * range`; `type Mutates = AddressOfOp | DefinitelyMutates | PossiblyMutates | NeverMutates`; predicates `isRecdOrStructTyconRefAssumedImmutable`, `isTyconRefReadOnly`, `isRecdOrStructTycon{Ref,Ty}ReadOnly`; `CanTakeAddressOf`, `CanTakeAddressOfImmutableVal`, `MustTakeAddressOfVal`, `MustTakeAddressOfByrefGet`, `CanTakeAddressOfByrefGet`, `Must/CanTakeAddressOfRecdFieldRef`, `CanTakeAddressOfUnionFieldRef`; builders `mkDerefAddrExpr`, `mkExprAddrOfExpr(Aux)`, `mkTupleFieldGet`, `mkAnonRecdFieldGet`, `mkRecdFieldGet`, `mkUnionCaseFieldGetUnproven`.
- `[<AutoOpen>] module ExprFolding` — `IterateRecursiveFixups` (work out recursive-`let` fixups), `JoinTyparStaticReq`; `type ExprFolder<'State>` (record of callbacks: `exprIntercept`, `valBindingSiteIntercept`, `nonRecBindingsIntercept`, `recBindingsIntercept`, `dtreeIntercept`, `targetIntercept`, `tmethodIntercept`); `ExprFolder0`; `FoldImplFile`; `FoldExpr`; `#if DEBUG ExprStats`.
- `[<AutoOpen>] module Makers` — literals `mk{String,Byte,UInt16,Unit,Int32,Int,Zero,One,Two,MinusOne,TypedZero,TypedOne}`; locals & refs `mkRefCellContentsRef`, `mk{RefCell,RefCellGet,Set}`; sequential/composition `mk{Sequential,ThenDo,CompGen,CompGenThenDo}Sequential`, `mkSequentials`, `mkGetArg0`; tuples `mk{AnyTupled,RefTupled(NoTypes|Vars)}`; records `mk{RecordExpr,AnonRecd}`; lists `mk{Nil,Cons}`; array `mkArray`; unbox/box `mk{Unbox,Box,IsInst}`; IL specs `mspec_Type_GetTypeFromHandle`, `fspec_Missing_Value`, `mkInitializeArrayMethSpec`, `mkInvalidCastExnNewobj`; and the full `mkCall*` family (see `TypedTreeOps.ExprOps.md` for the complete list), plus `mk{Null,Throw,Reraise*,Labelled,NullTest,NonNull{Test,Cond},IfThen}`, `primMkApp`, `mkApps(Aux)`, `mkExprAppAux`, `mkAppsAux`, `mkTyAppExpr`, `mkUnionCaseTest`.

**Key invariants**: All four modules are `[<AutoOpen>]`, so their members are visible to anything that `open FSharp.Compiler.TypedTreeOps`. The `Makers` `mkCall*` family is the single place where F# Core operator/seq/string calls are synthesized — the checker uses these, and ILXGen lowers the resulting `Expr.Op`/`Expr.Val` nodes.

**Cross-references**: `TypedTreeOps.Makers` implementations in the `.fs`, `TypedTreeOps.ExprConstruction.fsi` (lower-level `mk*`), `TypedTreeOps.Remap.fsi` (for `Remap`), `TcGlobals.fs` (the intrinsic `ValRef`s the `mkCall*` family references), `Checker.fs` (heavy consumer), `IlxGen.fs` (consumer of the results).
