# TypedTreeOps.ExprConstruction.fs

**Purpose**: "Defines derived expression manipulation and construction functions" — the big library of low-level typed-tree *construction* helpers (`mk*`): building lambdas, lets, binds, matches, conditionals, record/union/tuple field access, loops, exception handling, locals, and the large family of type decomposition/typing predicates, plus a few support modules (`TypedTreeCollections`, `TypeTesters`, `CommonContainers`). Most functions are `[<AutoOpen>]`ed into `FSharp.Compiler.TypedTreeOps` and take `TcGlobals` first.

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

- `TypeTesters` — the auto-opened type predicates and destructors listed above (implemented here in the .fs layout).
- `CommonContainers` — shared container utilities used by the construction code.

**Significant internal logic**: `valOrder`/`tyconOrder` order Vals/Tycons by stamp (stable deterministic serialization); `valSourceOrderKey` derives a stable source-position key `(fileIndex, line, col, name)` for ordering. `mkMultiLambdas(Core)` desugar a multi-argument function into a curried lambda-chain; `primMkMatch` builds an `Expr.Match` from a `DecisionTree` + `DecisionTreeTarget array`. The `actualTy*` functions compute the "instantiated" type field/type of a record/union case or field given a `TyparInstantiation`. The predicates (is*Ty) drive code-generation decisions (e.g. `isFSharpStructTy` → value-classification pass; `isRefTy` → `byref` handling).
