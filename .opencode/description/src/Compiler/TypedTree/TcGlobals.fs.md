# TcGlobals.fs

## Pipeline role

This file belongs to the TypedTree folder of the F# compiler. It is the *implementation* side of `TcGlobals.fsi`: it builds the single `TcGlobals` object that serves as the type checker's global environment, "pinning" every well-known FSharp.Core type/operator (as `IntrinsicValRef`) and BCL type/attribute that the compiler recognizes, so that identity-based recognition (optimized comparison/hashing calls, intrinsic operator substitution, witness generation, array/list/map/set lowering) can be done by reference equality rather than by name-string comparison. It is one of the largest single classes in the compiler (~1500 lines of constructor initialization computing ~540 members). The object is constructed early in `Checker.fs`/`FscCheck` and then threaded through checking, optimization and code generation.

## Module-global constants / bindings (outside the class)

- `let internal DummyFileNameForRangesWithoutASpecificLocation = startupFileName` and `let private envRange = rangeN … 0` — the range used for the rigid typars (`a`, `b`, …, the SRTP witness shapes).
- `IntrinsicValRef` — `| IntrinsicValRef of NonLocalEntityRef * string * bool * TType * ValLinkageFullKey` (`[<NoEquality; NoComparison; StructuredFormatDisplay("{DebugText}")>]`). The `bool` is "isMember"; the `ValLinkageFullKey` lets a *type-carrying* ref be reconstructed lazily by `ValRefForIntrinsic` → `mkNonLocalValRef mvr key`. `Name`, debug `DebugText`, `override ToString`.
- `[<AutoOpen>] module FSharpLib` — the F#-library namespace name constants (`Root = "Microsoft.FSharp"`, `Core`, `Control`, `Linq`, `Collections`, `LanguagePrimitives`, `CompilerServices`, `LinqRuntimeHelpers`, `ExtraTopLevelOperators`, `NativeInterop`, `Quotations`) plus precomputed `*Path` (list) / `*PathArray` (array) variants used to build `NonLocalEntityRef`s.
- `tname_*` `[<Literal>]` strings — quoted full names of matching BCL types/attributes (`System.Text.StringBuilder`, `System.Runtime.CompilerServices.CompilerGeneratedAttribute`, `System.Diagnostics.DebuggerHiddenAttribute`, `System.Reflection.Missing`, `System.FormattableString`, `System.Runtime.Serialization.*`, `System.Delegate`, `System.ValueType`, `System.Enum`, `System.FlagsAttribute`, `System.Array`, `System.RuntimeArgumentHandle`/`RuntimeTypeHandle`/`RuntimeMethodHandle`/`RuntimeFieldHandle`, `System.Runtime.CompilerServices.ReferenceAssemblyAttribute`, `Runtime.InteropServices.UnmanagedType`, `DebuggingModes`, `AsyncCallback`, `IAsyncResult`, `IsByRefLikeAttribute`, …).
- `CompilationMode` (`[<RequireQualifiedAccess>]`) — `Unset | OneOff | Service | Interactive`.
- `#if DEBUG` `let mutable global_g = None : TcGlobals option` at the very end — debug-only live instance.

### Local pre-computations (the "wiring" of the class)

**Nullness / type-building primitives**:
- `v_langFeatureNullness = langVersion.SupportsFeature LanguageFeature.NullnessChecking`; `v_knownWithNull`/`v_knownWithoutNull` degrade to `KnownAmbivalentToNull` when nullness checks are off.
- `mkNonGenericTy`, `mkNonGenericTyWithNullness`, `mkNonLocalTyconRef2`, and the `mk_MFCore_tcref`/`mk_MFQuotations_tcref`/`mk_MFLinq_tcref`/`mk_MFCollections_tcref`/`mk_MFCompilerServices_tcref`/`mk_MFControl_tcref` helpers that build `TyconRef`s to well-known FSharp.Core types by path array.
- Rigid typars `vara..vare` + their `TyparTy`s (used for the SRTP witness shapes).
- Signature-shape helpers: `mk_unop_ty`, `mk_binop_ty`, `mk_shiftop_ty`, `mk_rel_sig`, `mk_compare_sig`, `mk_hash_sig`, `mk_compare_withc_sig`, `mk_equality_withc_sig`, `mk_hash_withc_sig`, `mkSmallRefTupledTy`, `mkForallTyIfNeeded`, `mkIteratedFunTy`, `(-->)`, `mkNullableTy`, `mkByrefTy`, `mkNativePtrTy`, `mkFunTy`, `mkListTy`, `mkSeqTy`, `mkArrayType` (rank 1..32 via `v_il_arr_tcr_map`), `mkLazyTy`, `mkOptionTy`, `mkQuerySourceTy`, `mkPrintfFormatTy`, `mkQuotedExprTy`, `mkQueryBuilderTy`, `mkLinqExpressionTy`, etc.

**System-type lookup primitives** (backed by `tryFindSysTypeCcuHelper`):
- `findSysTypeCcu` returns a *delayed* `CcuThunk.CreateDelayed(dummyAssemblyNameCarryingUsefulErrorInformation …)` when the type is missing — i.e. a dangling CCU carrying a diagnostic name, so any attempt to dereference it yields `tcGlobalsSystemTypeNotFound` (`"the type %s is required here but is not referenced"` style) and not a generic failure.
- `findSysTyconRef`/`tryFindSysTyconRef`, `findSysILTypeRef`/`tryFindSysILTypeRef` (split IL name, resolve scope ref, `mkILTyRef`), `findSysAttrib`/`tryFindSysAttrib` (public types only), `findPublicSysAttrib`.
- `static let isInEmbeddableKnownSet` + `static member IsInEmbeddableKnownSet` — the whitelist of compiler-generated, embeddable attributes (`IsReadOnlyAttribute`, `IsUnmanagedAttribute`, `NullableAttribute`, `NullableContextAttribute`, `MemberNotNullWhenAttribute`, `DynamicDependencyAttribute`, `DynamicallyAccessedMemberTypes`).
- `findOrEmbedSysPublicType nm` — asserts the name is in the known set; if dereferencable, returns the found "real" attribute, otherwise constructs a fresh local `Construct.NewTycon` (empty module-or-type, `ILScopeRef.Local`) so the attribute can be *embedded* into the emitted assembly.
- `mutable embeddedILTypeDefs = ConcurrentDictionary<string, ILTypeDef>()` — the embed queue; `TryEmbedILType(tref, mkEmbeddableType)` only for `ILScopeRef.Local` scopes, keyed by name; `tryRemoveEmbeddedILTypeDefs()` drains it in key order (used by the IL emitter at the end of a compilation).

**Well-known FSharp.Core `NonLocalEntityRef`s** — `fslib_MF_nleref`, `fslib_MFCore_nleref`, `fslib_MFLinq_nleref`, … and nested modules: `LanguagePrimitives` (IntrinsicOperators, IntrinsicFunctions, HashCompare), `Operators` (OperatorIntrinsics, Unchecked, Checked), `ExtraTopLevelOperators`, `AsyncBuilder`, `NullableOperators`, `QueryRunExtensions` (LowPriority/HighPriority), `PrintfModule`, `SeqModule`, `ListModule`, `ArrayModule`/`Array2D..4DModule`, `SetModule`, `MapModule`, `StringModule`, `NativePtrModule`, `OptionModule`, `StateMachineHelpers`, `RuntimeHelpers`, `Quotations` (nested under `Microsoft.FSharp`), `LeafExpressionConverter`, `LazyExtensions`. These define the *compilation targets* of the known intrinsics and the module mapping for provided expressions.

**Well-known tycon refs** — all primitive `v_*_tcr` (`int`, `int32`, `int16/32/64`, `uint16/32/64`, `sbyte`, `byte`, `bool`, `string`, `char`, `float`, `float32`, `decimal`, `nativeint`/`unativeint`, `unit`/`Unit`, `obj`, `exn`, the `decimal`1`/`float`1`/`float32`1`/`int`1`… measurement-parameterized "p" variants), pointer/ref types (`byref`1`, `byref`2`, `outref`1`, `inref`1`, `nativeptr`1`, `voidptr`, `ilsigptr`1`), `FSharpFunc`2`, `ref`1`/`Ref`1`, `MatchFailureException`; the collections module types (`option`1`, `voption`1`, `list`1`/`List`1`, `seq`1`, `Lazy`1`, `PrintfFormat`5`/`4`, `DateTime`, `Nullable`1`, `Tuple`1..8`, `ValueTuple`1..8`, `Choice`2..7`, `IObservable`1`, `IObserver`1`, `IEvent`2`, `IDelegateEvent`1`, `Expr` / `Expr`1`, `QueryBuilder`/`QuerySource`2`, `System.Linq.Expressions.Expression`1`); BCL tycons via `findSysTyconRef` (`Attribute`, `Array`, `Type`, `RuntimeMethodHandle`, `System.String`, `TypeCode`-adjacent, `IComparer`, `IEqualityComparer`, `IEnumerable`1`, `IEnumerator`1`, `IFormattable`, `FormattableString`/`FormattableStringFactory`, `SupportsWhenTEnum`, `ResumableStateMachine`1`/`IResumableStateMachine`1`, `ListCollector`1`, `ArrayCollector`1`, `GeneratedSequenceBase`1`, `ByRefKinds.In/Out/InOut`, …). `v_il_arr_tcr_map` = `Array.init 32` building `[]`1` (rank 1) or `[,,…]`1` arities for rank 2..32.

**Well-known types (`*_ty`)** — `byte_ty`, `sbyte_ty`, `int16_ty`… `int_ty`, `int32_ty`, `uint32_ty`, `int64_ty`, `uint64_ty`, `float32_ty`, `float_ty`, `nativeint_ty`/`unativeint_ty`, `enum_ty` (= `v_int_ty`), `bool_ty`, `char_ty`, `string_ty` (+ `string_ty_ambivalent`), `decimal_ty`, `unit_ty`, `obj_ty_noNulls`/`obj_ty_ambivalent`/`obj_ty_withNulls`, `exn_ty`, the system `system_*` set (`system_Array_ty`, `system_Object_ty`, `system_IDisposable_ty` + null-carrying variant, `RuntimeHelpers`, `ValueType`, `Delegate`, `MulticastDelegate`, `Enum`, `Type`, `TypedReference`, `ArgIterator`, `RuntimeArgumentHandle`, `SByte`/`Int16`…`IntPtr`), tuple decoders (`decodeTupleTy`, `tryDecodeTupleTy`, `decodeTupleTyAndNullness(IfPossible)` for the 8+ arity trick using the marker element), and `v_cons_ucref`/`v_nil_ucref` (list `::`/`[]` union case refs).

**Internal tables**:
- `v_knownIntrinsics = ConcurrentDictionary<(string*bool*string*int-ish) …, ValRef>)` — registered via `makeIntrinsicValRefGeneral isKnown (enclosingEntity, logicalName, memberParentName, compiledNameOpt, typars, (argTys, retTy))`: builds the `ValLinkageFullKey` (member parent name, `MemberIsOverride=false`, logical name, arg count) and dedups/registers under `(LastItemMangledName, memberParentName, compiledName, argCount)`. `makeIntrinsicValRef` (registered) vs `makeOtherIntrinsicValRef` (not registered — used for on-the-fly SRTP-bound operators).
- `v_suppressed_types` — tycons whose *lowercase* names are "suppressed" by `findSysTyconRef` fallback logic (`Option`1`, `Ref`1`, `FSharpTypeFunc`, `FSharpFunc`2`, `Unit`).
- `v_knownFSharpCoreModules` — the name→`ERefNonLocal` dict of all known FSharp.Core modules (used when re-mapping provided expressions back to FSharp.Core functions; comment: "the more we list the better the job we do").
- `v_FSharpCoreForceInlineModules` — the always-inline set (`IntrinsicFunctions`, `IntrinsicOperators`, `LanguagePrimitives`, `Operators`, `OperatorIntrinsics`, `Checked`, `Unchecked`, `NativePtrModule`, `AsyncBuilder`) consumed by the inliner.
- `v_memoize_file` — a `MemoizationTable<int, ILSourceDocument>` keyed by file index computing `FileSystem.GetFullFilePathInDirectoryShim directoryToResolveRelativePaths` → resolved `ILSourceDocument`; exposed as `g.memoize_file` to minimize the number of `ILSourceDocument` objects.

**Well-known intrinsics (`*_info` / `*_vref`)** — the ~200 "operator" refs, e.g. `v_addrof_info`/`v_addrof2_info` (`~&`/`~&&`), `v_and2_info`/`v_or2_info`, `compare_operator`, `=`, `=?`/`?=`/`?=?` nullable operators, `<>`/`<`/`<=`/`>`/`>=`, `EnumOfValue`, the `generic_comparison/hash/equality` family with/without comparer and the `FastCompareTuple2..5`/`FastHashTuple2..5`/`FastEqualsTuple2..5` tuple specializations (via `HashCompare`), `reference_equality`, printer/piper (`%`/`|>`/`||>`/`|||>`), bool `&&`/`||`, `bitwise_*`, `( ** )`, unchecked arith, `array/set/get/length`, `exponentiation`, string `.Length`, `getstring`, `box`/`unbox`/`isnull`/`istype`, `create_instance`, `new_decimal`, `seq_*`, `splice_expr`/`splice_raw_expr` (`%`/`%%`), `deserialize_quoted_FSharp_20_plus` / `deserialize_quoted_FSharp_40_plus`, `check_this`, `call_with_witnesses`, `resolvecall`, `cast_quotation`, `GetArray2D..4D`, `failwith`, `failwithf`, `invalid_arg`, `invalid_op`, `raise`, `reraising`, `dispose`, `enum`, `tryfinally`, `trywith`, `runtimetype` etc. — each represented both as `IntrinsicValRef` (info, with type+linkage) and as a derived `ValRef` (`*_vref`, via `ValRefForIntrinsic`). Witness-carrying call info includes `nWitnesses` fields. All the `attrib_*` well-known `BuiltinAttribInfo` values (both FSharp.Core attrs via `mk_MFCore_attrib`/`mk_MFCompilerServices_attrib` and BCL attrs via `findSysAttrib`) are initialized here too, including `attribs_Unsupported` (attributes the compiler knows about but doesn't support: `ModuleInitializerAttribute`, `CallerArgumentExpressionAttribute`, `UnmanagedCallersOnlyAttribute`, `CompilerFeatureRequiredAttribute`, `SetsRequiredMembersAttribute`, `RequiredMemberAttribute`).

**Type identity / "better type" tables**:
- `betterTyconEntries` — the "improve" mapping: BCL primitive tycons → F# tycons (`System.Int32`→`v_int_tcr`, `IntPtr`→`nativeint`, `UIntPtr`→`unativeint`, `Int16`/`Int64`/`UInt16`/`UInt32`/`UInt64`/`SByte`/`Decimal`/`Byte`/`Boolean`/`String`/`Object`/`Exception`/`Char`/`Double`/`Single`, and `IEnumerable``1`→`seq``1` when not compiling FSharp.Core) with per-arity/nullness builders.
- `decompileTyconEntries` — `FSharpFunc``2`→fun type, and `Tuple``2..8`/`ValueTuple``2..8`→`TType_tuple` (via the tuple decoders).
- `decompileTypeDict`/`betterTypeDict1`/`betterTypeDict2` — lazily-built dictionaries keyed by tycon *stamp* (or by *name*, `betterTypeDict1`, used while building FSharp.Core.dll when the target tycons may not exist yet and can't be dereferenced). Lazy so no deref happens during setup of the base imports.
- `decompileTy tcref tinst nullness` — equates F# with .NET types, e.g. `TType_tuple == System.Tuple/ValueTuple`; no-op when compiling FSharp.Core. "Fairly performance critical" — invoked heavily during `.NET metadata → F# internal data` conversion (import.fs).
- `improveTy` — cosmetic improvement `Int32 → int32`; same caveats.

**Generated-attribute emitters** — `debuggerNonUserCodeAttribute`, `compilerGeneratedAttribute` bases; `generatedAttributes` (`[|CompilerGenerated; DebuggerNonUserCode|]` unless `noDebugAttributes`); `addGeneratedAttrs` (appends to IL attr arrays), `addValGeneratedAttrs` (Lisp-style cons onto `Val.Attribs`), `addMethodGeneratedAttrs`/`addPropertyGeneratedAttrs`/`addFieldGeneratedAttrs` (`.With(customAttrs = …)`), `tref_DebuggerBrowsableAttribute n`, `debuggerBrowsableNeverAttribute`, `addNeverAttrs`/`addPropertyNeverAttrs`/`addFieldNeverAttrs`, `mkDebuggerTypeProxyAttribute`, `mkDebuggerDisplayAttribute`, `mkDebuggableAttributeV2` (computes the `DebuggingModes` bitmask: `0x3` base + 1=jit-tracking + 256=jit-optimizer-disabled; emits against the nested `DebuggingModes` enum type), `MakeInternalsVisibleToAttribute simpleAssemName`.

## Notable members / logic (spot-selected; full member list in `TcGlobals.fsi.md`)

- Identity comparators `unionCaseRefEq` / `valRefEq` — `primUnionCaseRefEq` / `primValRefEq compilingFSharpCore fslibCcu x y` (the FSharp.Core-aware reference equality predicates).
- `generateWitnesses` — `compilingFSharpCore || (call_with_witnesses_info.TryDeref.IsSome && langVersion…WitnessPassing)`.
- `isArrayEmptyAvailable` — derived by inspecting `System.Array.Empty`'s presence in IL metadata.
- `isSpliceOperator v` — ref-equals `v` to `splice_expr_vref` or `splice_raw_expr_vref`.
- `MakeBuiltInWitnessInfo t` — for an SRTP trait `t` returns `(vref, tinst)` pointing at the matching `LanguagePrimitives.*Dynamic` function: strips `op_` prefits, maps `get_Zero/get_One` → `GenericZero/GenericOne`, and selects the arity pattern (`…Dynamic` binary/ternary/unary/`DivideByInt`/zero) to instantiate `[vara;varb;varc]`.
- `TryMakeOperatorAsBuiltInWitnessInfo isStringTy isArrayTy t argExprs` — maps traits onto concrete FSharp.Core operators for direct call (no witness): `get_Sign`→`Operators.sign`, `Sqrt`→`sqrt`, `Pow`→`( ** )`, `Atan2`→`atan2`, `get_Zero/get_One`→`GenericZero/GenericOne` (with or without an arg), the single-arg math ops (with `Ceiling→ceil` lowercasing), array `get_Item`/`set_Item`, string indexer `get_Item`→`getstring`, `op_UnaryPlus`→`Operators.id`.
- The hundreds of `member`/`member val` accessors returning the precomputed `v_*` values — trivially separated into: tycon refs (`.tcr`), types (`.ty`), `BuiltinAttribInfo` (`.attrib_*`), `IntrinsicValRef` (`.info`) and `ValRef` (`.vref`) pairs, plus feature-flag/configuration members (`checkNullness`, `langFeatureNullness`, `knownWithNull`/`knownWithoutNull`, `isInteractive`, `compilationMode`, `noDebugAttributes`, `realsig`, `pathMap`, `langVersion`, `emitDebugInfoInQuotations`, `useReflectionFreeCodeGen`, `compilingFSharpCore`, `fslibCcu`, `ilg`, `tryFindSysTypeCcuHelper`, `directoryToResolveRelativePaths`).
- `member internal CompilerGlobalState = Some compilerGlobalState` — the per-compilation `CompilerGlobalState` (created in the constructor) exposed for hot-reload/E&C name-map access.
- `override ToString() = "<TcGlobals>"`.

## Relation to the signature

Implements every `.fsi` declaration; the `.fsi` documents the full public surface (incl. the `FSharpLib` `[<AutoOpen>]` module and `IntrinsicValRef`/`CompilerGlobalState`). The `.fs` additionally defines the constructor internals, the `DummyFileNameForRangesWithoutASpecificLocation` binding, workspace tables (`decompileTypeDict` etc.), and the `#if DEBUG` `global_g` hook.
