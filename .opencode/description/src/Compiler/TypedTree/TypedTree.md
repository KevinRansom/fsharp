# TypedTree.fs

**Purpose**: The central typed (checked) AST representation of the F# compiler: the fully-typed tree the type checker (`Checker.fs`, via `Tast`) produces and that the backend (ILXGen, `Quotations`, documentation/sig generation) consumes. A typed-tree value (`Val`) carries its parameters, body expr (an `Expr`), type, typar/constraint info, linkage key and well-known-attribute cache; a `Tycon` (`Entity`) carries representation/augmentation, union cases/record fields; `ModuleOrNamespaceType` is the checked module/namespace body. This is a "checked" AST: it is the result of type checking (hence the task's `ExprVal`/`ExprPat`/`TypedVal`/`TypedModule` family corresponds to `Expr`/`Val`/`Entity`/`ModuleOrNamespaceType` here), not a source syntactic one.

**Namespace(s)**: `FSharp.Compiler` — `module internal rec FSharp.Compiler.TypedTree`.

**Declared types** (~90; one-line roles):
- `Stamp = int64`, `StampMap<'T>` — identity stamps/maps for entities.
- `ValInline` (inherited/inlined val), `ValRecursiveScopeInfo`, `ValMutability`, `TyparDynamicReq`, `ValBaseOrThisInfo`.
- `ValFlags(flags: int64)` — `[<Flags>]` val flags (inline, isPropertyIsSet, etc.); `TyparKind`, `TyparRigidity`, `TyparFlags`, `EntityFlags`.
- `ModuleOrNamespaceKind` (Module|Namespace), `PublicPath` (string[]), `SyntaxAccess`, `CompilationPath`, `EntityOptionalData`.
- `Entity` — the big checked entity: name, `kind: ModuleOrNamespaceKind`, `Typars`, members, `Attribs`, constraints, `ModuleOrNamespaceType` body (for modules) *or* `UnionCase list`/`RecdField list` + tycon representation (for record/union), `ExceptionInfo`. (In the current codebase this is the `Tycon`/`ModuleOrNamespace`/`Entity` — the task's `TypedMember`/`TypedProperty`/`TypedConstructor`/`TypedParameter` concepts appear as members/val info on `Entity`/`Val`.)
- `EntityData = Entity`, `ParentRef`, `CompiledTypeRepr`, `TyconAugmentation`, `TyconRepresentation`, `TILObjectReprData`, `TProvidedTypeInfo`, `FSharpTyconKind` (Struct|Enum|Record|Union|Class|Interface|Other), `FSharpTyconData`, `TyconRecdFields`, `TyconUnionCases`, `TyconUnionData`.
- `UnionCase`, `RecdField`, `ExceptionInfo`, `ModuleOrNamespaceType` (checked module/namespace: `Values`, `ModuleAndNamespaceDefinitions`, `UnionCases`, `Attribs`), `ModuleOrNamespace = Entity`, `Tycon = Entity`.
- `Accessibility` (public/internal/private with `CompilationPath` restriction), `TyparOptionalData`, `TyparData = Typar`, `Typar`, `TyparConstraint` (`TyparConstraint` of Type|Trait with constraints).
- `TraitWitnessInfo`, `TraitConstraintInfo`, `TraitConstraintSln`.

- `ValMemberInfo`, `NonLocalValOrMemberRef`, `ValPublicPath`, `NonLocalEntityRef` (checked reference across CCUs: `path, id, compPath, publicPath, access, ccu`), `EntityRef` (local or nonlocal entity ref: `ERefLocal|ERefNonLocal|ERefNonLocalPreResolved`), `ModuleOrNamespaceRef = EntityRef`, `TyconRef = EntityRef`, `ValRef`, `UnionCaseRef`, `RecdFieldRef`.
- `NullnessInfo`, `Nullness`, `NullnessVar`, `TType` (checked type: `TTypar|TGenericParam|TArrow|TAnonymous|TAmbientUnit|TAbbrev|TApp|TEnumVal|TDelayed|TMeasure|TRawMetadata...` — the central checked type), `TypeInst`, `TTypes`, `AnonRecdTypeInfo`, `TupInfo`, `Measure`.
- `WellKnownEntityAttribs = WellKnownAttribs<Attrib, WellKnownEntityAttributes>`, `WellKnownValAttribs`, `Attribs = Attrib list`, `AttribKind`, `Attrib`, `AttribExpr`, `AttribNamedArg`.
- `Const` (checked constants: `ConstValue` of Bcl|Float32|Float64|String|Char|Int8..Uint64|NativeInt|UnativeInt|Boolean|EnumVal|Array|ByteArray|Array2D..Array4D|ArraySegment|CharArray|ByteArraySegment|Float32Array|Float64Array|Guid|Decimal|DateTime|Byte|SByte|Int16|Int32|Int64|UInt16|UInt32|UInt64|IntPtr|UIntPtr|ByRefKind...), `DecisionTree`, `DecisionTreeCase`, `ActivePatternReturnKind`, `DecisionTreeTest`, `DecisionTreeTarget`, `Bindings`, `Binding`, `ActivePatternElemRef`.
- `ValReprInfo`, `ArgReprInfo`, `TyparReprInfo`, `Typars`, `Exprs = Expr list`, `Vals = Val list`.
- `Expr` (the central **checked expression**) — `Const, Val, Sequential, Lambda, TyLambda, App, LetRec, Let, Obj, Match, StaticOptimization, Op, Quote, WitnessArg, TyChoose, Link, DebugPoint`; methods `DebugText`, `ToDebugString`, `Range`.
- `TOp` (checked operator/intrinsic: `TOp_Nil|TOp_Next|TOp_Try|TOp_TryWith|TOp_Sequence|TOp_...|TOp_AddressOf|TOp_ValueCast|TOp_MeasureCast|TOp_FieldGet|TOp_FieldSet|TOp_RecordGet|TOp_RecordSet|TOp_UnionTag|TOp_UnionGet|TOp_AddressSet|...` — the checked intrinsic/operator node).
- `RecordConstructionInfo`, `ConstrainedCallInfo`, `SpecialWhileLoopMarker`, `ForLoopStyle`, `LValueOperation`, `SequentialOpKind`, `ValUseFlag`, `StaticOptimization`, `ObjExprMethod`, `SlotSig`, `SlotParam`, `OpenDeclaration`, `ModuleOrNamespaceContents`, `ModuleOrNamespaceBinding`, `NamedDebugPointKey`.
- `CheckedImplFile` (a checked implementation file with its `ModuleOrNamespaceType` and values), `CheckedImplFileAfterOptimization`, `CheckedAssemblyAfterOptimization`.
- `CcuData` (checked-compiler-unit data: the CCU metadata of a compilation: `Values`, `ModuleAndNamespaceDefinitions`, `UnionCases`, `Attribs`...), `CcuTypeForwarderTree`, `CcuTypeForwarderTable`, `CcuReference = string` (IL assembly ref), `CcuThunk` (a thunk carrying either a loaded F# CCU or an IL one — `CcuThunkLoaded|CcuThunkIL`), `CcuResolutionResult`, `PickledCcuInfo` (the pickled form stored in .fasl).
- `FreeLocals = Zset<Val>`, `FreeTypars = Zset<Typar>`, `FreeTycons = Zset<Tycon>`, `FreeRecdFields = Zset<RecdFieldRef>`, `FreeUnionCases = Zset<UnionCaseRef>`, `FreeTyvars`, `FreeVarsCache`, `FreeVars` (free-vars info: locals, typars, tycons, record fields, union cases).
- `Construct` (static class) — constructors used in checking: `NewTypar`, `NewTycon`, `NewModuleNamespaceType`, `NewVal`, `NewExpr`, etc.

**Public API surface** (internal to compiler): the entire surface above is `internal`; key entry points are the type constructors (`Val`, `Expr`, `Entity`, `ModuleOrNamespaceType`), the reference constructors (`ValRef`, `EntityRef`, `TyconRef`, `UnionCaseRef`, `RecdFieldRef`), the type constructors (`TType`, `Typar`, `Tycon`), the CCU/`CcuThunk`/`PickledCcuInfo` types (for pickling), and the `FreeVars` family (for free-var analysis in `TypedTreeOps.FreeVars.fs`).

**Internal helpers / active patterns**: `ERefLocal|ERefNonLocal`, `VRefLocal|VRefNonLocal`, `ValDeref`, `AbbrevOrAppTy`, `ILTyconRawMetadata` (see `TypedTreeBasics.fs`); `getNameOfScopeRef`; `WellKnownNames.CopyOfStruct`.

**Significant internal logic**: `Val.Linkage: ValLinkageFullKey` and `Val.Typars` (with `TyparFlags`) drive cross-CCU identity; `Expr.App` normalizes sequential applications into a single `args: Exprs`; `Expr.Match` stores a `DecisionTree` + `targets` array (the decision-tree form of pattern matching); `Expr.Quote` carries `quotationInfo` (mutable ref, filled by the picker) and `isFromQueryExpression`; `Expr.WitnessArg` is spliced for trait witnesses (see comment around "spliced into a quotation literal"); `Expr.Link` is a link node replaced by a Val ref after tc of recursive bindings; `Expr.TyChoose` is the "free choice of typars" node that minimization of polymorphism at `let rec` produces and which is later resolved. `CcuThunk` is the key indirection for cross-assembly resolution (lazy loading of a F# or IL assembly).

**Cross-references**: `TypedTree.fsi` (contract), `TypedTreeBasics.fs` (shared helpers), `TypedTreeOps.*` (attributes, free vars, remap, remapping, transforms, expr construction, expr ops), `TypedTreePickle.fs` (pickling), `TypeProviders.fs` (type providers), `tainted.fs` (taint), `QuotationPickler.fs` (quotations), `SynthesizedTypeMaps.fs`, `CompiledNames.fs`, `Checker.fs` (producer), `IlxGen.fs` (consumer).
