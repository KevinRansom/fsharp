# TypedTreeOps.Attributes.fsi

**Purpose**: Contract for the attribute-recognition and classification machinery: classifying each `Attrib`/`ILAttribute` into its `WellKnown*Attributes` bit flag (entity/val/assembly), computing and caching the aggregate flags ("avoid O(N) linear scans of attribute lists"), and exposing the large family of payload-extraction active patterns (`EntityAttrib`, `ValAttrib`, `EnumExpr`, `TypeOfExpr`, `UnopExpr`, `BinopExpr`, `ConstExpr`, `NameOfExpr`, `SeqExpr`, `Span-like` ty, …) used throughout the checker and backend.

**Namespace(s)**: `FSharp.Compiler.TypedTreeOps`.

**Modules** (see `TypedTreeOps.Attributes.md` for the full list):
- `module ILExtensions` — `isILAttribByName`, `TryDecodeILAttribute`, `IsILAttrib`, `TryFindILAttribute`, `hasFlag` (generic `enum<uint64>`), `classifyILAttrib`, `computeILWellKnownFlags`, `tryFindILAttribByFlag`, `(|ILAttribDecoded|_|)`.
- `module AttributeHelpers` — F#-attribute recognition (`IsMatchingFSharpAttribute`, `HasFSharpAttribute`, `TryFindFSharpAttribute`), payload patterns (`ExtractAttribNamedArg`, `ExtractILAttributeNamedArg`, `StringExpr`, `AttribInt32Arg`/`Int16/Bool/String`, `AttribElemStringArg`), classification (`computeEntityWellKnownFlags`, `classifyEntityAttrib`, `classifyValAttrib`, `classifyAssemblyAttrib`, `attribsHave{Entity,Val}Flag`, `filterOutWellKnownAttribs(+valMask)`, `tryFind{Entity,Val}AttribByFlag`, `(|EntityAttrib(Int|String)|_|)`, `(|ValAttrib(Int|String)|_|)`), entity/val/tycon queries (`EntityHasWellKnownAttribute`, `GetEntityWellKnownFlags`, `ValHasWellKnownAttribute`, `ArgReprInfoHasWellKnownAttribute`, `ValTryGetBoolAttribute`, `EntityTryGetBoolAttribute`, `TyconRef{Has,TryFindBool,String,HasWellKnown}Attribute(ByName|Fast)`, `TyconRefAllowsNull`, `TryFindAttributeUsageAttribute`), expression patterns (`AttribBitwiseOrExpr`, `EnumExpr`, `TypeOfExpr`, `TypeDefOfExpr`, `isNameOfValRef`, `NameOfExpr`, `SeqExpr`, `UnopExpr`, `BinopExpr`, `Specific{Unop,Binop}Expr`, `SignedConstExpr`, `IntegerConstExpr`, `FloatConstExpr`, `UncheckedDefaultOfExpr`, `SizeOfExpr`), attribute builders (`mkCompilationMappingAttr*`, `mkCompilationArgumentCountsAttr`, `mkCompilationSourceNameAttr`, `mkCompilationMappingAttrForQuotationResource`), provider/signature helpers (`TryDecodeTypeProviderAssemblyAttr`, `IsSignatureDataVersionAttr`, `TryFindAutoOpenAttr`, `TryFindInternalsVisibleToAttr`, `IsMatchingSignatureDataVersionAttr`, `mkSignatureDataVersionAttr`), semantic queries (`isSealedTy`, `IsUnionTypeWithNullAsTrueValue`, `TyconHas{UseNullAsTrueValueAttribute,CanHaveUseNullAsTrueValueAttribute}`, `ModuleNameIsMangled`, `CompileAsEvent`, `ValCompileAsEvent`, `MemberIsCompiledAsInstance`, `ValSpecIsCompiledAsInstance`, `ValRefIsCompiledAsInstanceMember`), extension attrs (`tryFindExtensionAttribute`, `tryAddExtensionAttributeIfNotAlreadyPresentFor{Module,Type}`), byref/Span (`isByrefLike{TyconRef,Ty}`, `isSpanLike{TyconRef,Ty}`, `isSpanTy`, `tryDestSpanTy`, `destSpanTy`, `isReadOnlySpanTy`, `tryDestReadOnlySpanTy`, `destReadOnlySpanTy`).
- `module ByrefAndSpanHelpers` — byref-likeliness / `Span<T>` helpers.
- `module DebugPrint` — `layoutValReprInfo/layoutStamps/layoutRanges/layoutTypes` (mutable switches), `showType`, `showExpr`, `valRefL`, `unionCaseRefL`, `valAtBindL`, `intL`, `valL`, `typarDeclL`, `traitL`, `typarL`, `typarsL`, `typeL`, `slotSigL`, `entityL`, `bindingL`, `exprL`, `tyconL`, `decisionTreeL`, `implFileL`, `implFilesL`, `recdFieldRefL`, `serializeEntity`.

**Contract notes**: The classification results are the `WellKnown*Attributes` flag enums (see `WellKnownAttribs.fsi`); the `hasFlag`/`compute*WellKnownFlags` pair is the core "classify one" vs "classify many" split used to populate the cached `WellKnownAttribs<'TItem,'TFlags>` wrappers on `Entity.attribs` and `Val.attribs`. Payload patterns return `voption`s (no equality constraints needed on `Expr`).
